# sber500-dashboard Specification

## Purpose
Дашборд метрик команды для организаторов Sber500: три числа по дням без доступа к разговорам и к внутренним системам.

## Requirements

### Requirement: Метрики по дням для Sber500

Сервис дашборда SHALL отдавать по адресу `/dashboard` страницу, а по `/dashboard/api` — JSON с тремя числами за каждые из последних 7 полных суток по Москве.

- **Активные (DAU)** — люди, у которых больше 10 реплик за сутки.
- **Вызовы LLM** — все вызовы моделей агента за сутки (трассы Langfuse).
- **Пользователи** — аккаунты, у которых за всё время больше 3 реплик, нарастающим итогом на конец суток.

Реплики считаются по базе агента, тестовые аккаунты не исключаются. Наружу MUST уходить только суммы: ни текстов, ни идентификаторов людей.

Поверхности: dashboard

#### Scenario: Страница
- **WHEN** организатор открывает `/dashboard` с верными логином и паролем
- **THEN** видит графики и таблицу за 7 последних полных суток, определения метрик и время пересчёта

#### Scenario: JSON
- **WHEN** запрос `GET /dashboard/api` с верными логином и паролем
- **THEN** ответ содержит период, время пересчёта, определения и по каждому дню `date`, `active_users`, `llm_calls`, `users_total`

#### Scenario: Сутки без активности
- **WHEN** за сутки нет ни одной реплики
- **THEN** у этих суток активных и вызовов 0, а пользователей столько же, сколько накануне

### Requirement: Вход и нагрузка

Дашборд SHALL пускать только по basic auth с одной учётной записью. Неудачные входы MUST быть ограничены: не больше 10 в минуту с одного IP. Числа SHALL пересчитываться не чаще раза в час и сразу после смены суток; запросы к странице базу и Langfuse не трогают.

Поверхности: dashboard

#### Scenario: Без пароля
- **WHEN** запрос без логина и пароля или с неверными
- **THEN** ответ 401, данных нет

#### Scenario: Перебор пароля
- **WHEN** с одного IP за минуту больше 10 неверных входов
- **THEN** до конца минуты этот IP получает 429

#### Scenario: Повторные открытия
- **WHEN** страницу открывают много раз в течение часа
- **THEN** база и Langfuse запрашиваются один раз

#### Scenario: Источник недоступен
- **WHEN** пересчёт не удался, а прошлый результат есть
- **THEN** отдаётся прошлый результат; если прошлого нет — 503

### 2.2 Извлекатель заметок по ходу разговора

#### Что сделать

- **Фон:** задачи не задерживают ход, сбой модели — повтор на следующем ходе.
- **Промпт** в `agent/app/memory/prompts/`. Модель — `MEMORY_NOTES_MODEL` через прокси программы. Учёт в `model_usage` (`component=memory`).

### 0.1 Решения владельца по памяти

#### Что сделать
Решить открытые вопросы `memory-design.md` и записать решения туда:
1. **Память по умолчанию** для новых аккаунтов (как у Claude и конкурента) и как один раз спросить существующих (D9).
2. **Самочувствие («плохо спит», «устаёт») — чувствительное или обычное?** У Claude здоровье по умолчанию не сохраняется. Но для приложения эмоциональной поддержки это основной контекст. Предложение: самочувствие — обычная категория, чувствительные — вера, взгляды, интимное. Вместе с психологом.
3. **Охват поиска по прошлым разговорам при включении.** Предложение: все разговоры журнала, кроме «Без памяти».
4. **Итог после кризиса** — не считать вовсе или не показывать в карточке «В прошлый раз».
5. **Импорт памяти из других ассистентов.** Делаем ли следующим шагом.

### 2.2 Извлекатель заметок по ходу разговора

#### Что сделать
По `memory-design.md`, D2:
- **Вход:** новые реплики человека по курсору, две последние реплики агента как контекст, живые заметки.
- **Выход:** операции `add`, `update`, `delete` (только по явной просьбе), `none`, с категорией и признаком «чувствительное».
- **Частота:** не чаще одного прохода на две реплики или раз в 20 секунд. Финальный проход при любом завершении, включая `end_stale` и `start(new)`.
- **Фон:** задачи не задерживают ход, сбой модели — повтор на следующем ходе.
- **Промпт** в `agent/app/memory/prompts/`. Модель — `MEMORY_NOTES_MODEL` через прокси программы. Учёт в `model_usage` (`component=memory`).

# Дельта-спецификация: memory-search

Остаток change'а на 2026-10-27. Индекс прошлых разговоров, его состав, очередь, удаление и подавление реплик уже работают и описаны в `openspec/specs/memory-search`; здесь два расхождения с первоначальным замыслом, которые в коде ещё не сделаны.

## MODIFIED Requirements

### Requirement: Переключатель «Опираться на прошлые разговоры»
Поиск по прошлым разговорам SHALL управляться отдельным переключателем «Опираться на прошлые разговоры» (подсказка: «Рядом может вспомнить, что ты говорил раньше, дословно»). Он включён по умолчанию, меняется без листа согласия вызовом `PUT /api/memory/settings` с `chatSearchEnabled`, а значение приходит в `GET /api/memory` как `chatSearchEnabled`. Пока «Память» выключена или недоступна, переключатель неактивен и поиск не используется. Выключение MUST удалять индекс прошлых разговоров человека целиком (через очередь с повторами), останавливать поиск в разговоре сразу и снимать ожидающие операции индекса; журнал и заметки остаются. Включение MUST пересобирать индекс в фоне из всех завершённых разговоров журнала, которые не удалены и не «Без памяти». Пока идёт пересборка, раздел «Память» SHALL показывать «Готовлю память о прошлых разговорах…»: агент отдаёт признак пересборки в `GET /api/memory`, клиенты показывают подпись, пока он установлен.

Поверхности: agent · api · web · pwa · android · ios · tg

#### Scenario: Выключить поиск
- **WHEN** человек выключил «Опираться на прошлые разговоры»
- **THEN** индекс удаляется целиком, находок в разговоре больше нет, журнал и заметки на месте
- **AND** открытая сессия голоса к следующему ходу открывается заново без прежних находок (см. capability `dialog-voice`)

#### Scenario: Включить поиск
- **WHEN** человек снова включил «Опираться на прошлые разговоры»
- **THEN** индекс в фоне пересобирается из завершённых разговоров журнала, кроме удалённых и «Без памяти»

#### Scenario: Идёт пересборка
- **WHEN** человек включил «Опираться на прошлые разговоры», и индекс ещё пересобирается
- **THEN** в разделе «Память» видна подпись «Готовлю память о прошлых разговорах…», а когда пересборка закончилась, она исчезает

#### Scenario: (web) Память на паузе
- **WHEN** «Память» выключена
- **THEN** переключатель «Опираться на прошлые разговоры» неактивен, ранее выбранное значение сохранено

#### Scenario: По умолчанию включён
- **WHEN** человек включает память впервые
- **THEN** `chatSearchEnabled` равен `true`

### Requirement: Находки из прошлых разговоров в разговоре
Пока «Память» и «Опираться на прошлые разговоры» включены, агент SHALL после каждой реплики человека искать в его индексе реплики, близкие по смыслу, в фоне и не задерживая ход. Найденное (без реплик, подавленных удалением заметки), не больше 600 знаков вместе с датой разговора, попадает в блок памяти под заголовком «Из прошлых разговоров (слова человека, дословно):» при ближайшей смене сессии голоса (см. capability `dialog-voice`). Остаётся последняя непустая находка. Сбой, медленный ответ или недоступность индекса MUST NOT мешать ходу: берётся то, что есть. На паузе, при выключенном поиске и в разговоре «Без памяти» находки в блок не попадают. Реплики и заметки одного человека MUST NOT находиться у другого.

Поверхности: agent

#### Scenario: Вспомнить сказанное раньше
- **WHEN** две недели назад человек рассказывал о ссоре с сестрой, а сейчас снова говорит о сестре
- **THEN** в блоке памяти следующей сессии есть дословная реплика того разговора с датой разговора из заголовка документа

#### Scenario: Длинная находка
- **WHEN** найденные реплики вместе с датой длиннее 600 знаков
- **THEN** в блок памяти попадают первые 600 знаков

#### Scenario: Поиск упал
- **WHEN** поиск по индексу отвечает ошибкой
- **THEN** ход не задерживается, блок памяти собирается из заметок и прежней находки

#### Scenario: Пауза
- **WHEN** «Память» на паузе
- **THEN** поиск по реплике не выполняется, блока памяти нет

# Дельта-спецификация: telegram-mini-app

Один пункт «Память» на первом экране рядом с тремя обязательными согласиями. Остальное в требовании без изменений, кроме пояснения под кнопкой: оно не обещает сохранить разговоры, как в базе; смысл пункта — требование «Память по умолчанию у новых аккаунтов» в `specs/memory-notes/spec.md`.

## MODIFIED Requirements

### Requirement: Первый экран в Mini App
Первый экран `/welcome/` в Mini App SHALL создавать аккаунт для Telegram-пользователя, а не для телефона: те же три согласия (18+, «это не психотерапия», условия и обработка данных), поле «Как к тебе обращаться» с подсказкой из имени в профиле Telegram (не длиннее 64 знаков) и кнопка «Начать», а под тремя согласиями — необязательный неотмеченный пункт о памяти (см. `memory-notes`). Имя MUST сохраняться только в том виде, в каком оно стоит в поле в момент нажатия «Начать», — его можно изменить или стереть; имя, которое у аккаунта уже есть, остаётся. Имя из Telegram MUST NOT отправляться само по себе. Под кнопкой — пояснение, что аккаунт привязан к Telegram и открывается в Telegram на любом устройстве, а почту для входа вне Telegram можно добавить в профиле. Пояснение MUST NOT обещать, что разговоры сохранятся: они стираются через 90 дней после последнего сообщения у всех аккаунтов (см. capability `data-retention`).

Поверхности: tg

#### Scenario: Подпись первого экрана
- **WHEN** в Mini App открыт `/welcome/`
- **THEN** под названием стоит «Когда нужно, чтобы кто-то был рядом. Вход через твой Telegram — без почты и паролей.»

#### Scenario: Подсказка имени
- **WHEN** в Mini App открыт `/welcome/` у человека с именем «Анна» в профиле Telegram
- **THEN** поле «Как к тебе обращаться» содержит «Анна», на сервер оно уходит только после «Начать»

#### Scenario: Имя стёрто
- **WHEN** человек стёр имя в поле и нажал «Начать»
- **THEN** аккаунт создаётся без имени

#### Scenario: Пункт о памяти
- **WHEN** в Mini App открыт `/welcome/`
- **THEN** под тремя согласиями стоит неотмеченный пункт о памяти, и «Начать» работает без него

#### Scenario: Согласия не даны
- **WHEN** человек нажимает «Начать», не отметив все три согласия
- **THEN** показано «Чтобы начать, нужны все три согласия», аккаунт не создаётся

#### Scenario: Аккаунт уже есть
- **WHEN** человек вернулся после выхода и у его аккаунта уже есть имя
- **THEN** имя из поля не затирает прежнее

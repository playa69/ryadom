# Дельта-спецификация: account-auth

Один пункт «Память» на первом экране рядом с тремя обязательными согласиями. Остальное в требовании без изменений (сценарий «Предупреждение о сроке» повторяет базу: два срока, разговоры 90 дней и гостевой аккаунт 90 дней, PROTEUS-246); смысл пункта — требование «Память по умолчанию у новых аккаунтов» в `specs/memory-notes/spec.md`.

## MODIFIED Requirements

### Requirement: Первый экран: приветствие и три согласия

Первый экран SHALL предлагать начать разговор без регистрации и требовать три отдельных согласия: «Мне есть 18 лет»; «Я понимаю, что «Рядом» — сервис самоподдержки, а не психотерапия и не медицинская помощь»; принятие условий использования и согласие на обработку персональных данных с политикой (ссылки на `/terms` и `/privacy` сайта). Кнопка «Начать» MUST работать только при всех трёх согласиях. Под ними идёт четвёртый, необязательный пункт о памяти с текстом «Память» (см. `memory-notes`): он не отмечен заранее и на кнопку не влияет. После нажатия клиент создаёт аккаунт на устройстве (см. «Вход без регистрации по устройству») и записывает согласия для него (см. «Запись согласий»).

Поверхности: web · pwa · android · ios

#### Scenario: Начало разговора
- **WHEN** человек отметил все три согласия и нажал «Начать»
- **THEN** клиент входит по устройству, записывает согласия и открывает главный экран
- **AND** ничего вводить не нужно: ни почты, ни пароля, ни имени

#### Scenario: Пункт о памяти
- **WHEN** человек видит первый экран
- **THEN** под тремя согласиями стоит неотмеченный пункт о памяти, и «Начать» работает без него
- **AND** отметка пункта записывает согласие на память вместе с остальными (см. `memory-notes`, «Память по умолчанию у новых аккаунтов»)

#### Scenario: Согласия отмечены не все
- **WHEN** человек нажимает «Начать» без одного или нескольких согласий
- **THEN** запрос не отправляется, видно «Чтобы начать, нужны все три согласия»
- **AND** (веб) фокус переходит на первый неотмеченный флажок, а неотмеченные подсвечиваются

#### Scenario: Ссылки на документы
- **WHEN** человек нажимает «условия использования» или «политикой»
- **THEN** документ сайта открывается вне экрана согласий, а флажок не переключается

#### Scenario: Предупреждение о сроке
- **WHEN** первый экран показан не в Telegram
- **THEN** под кнопкой сказано «Разговоры хранятся 90 дней после последнего сообщения. Без почты аккаунт удаляется через 90 дней без визитов.», а привязать почту можно в любой момент в профиле (смысл двух сроков и остальные места с этим текстом — в `data-retention`)

#### Scenario: Уже есть аккаунт
- **WHEN** человек нажимает «У меня уже есть аккаунт»
- **THEN** открывается экран входа по почте

#### Scenario: Сбой начала
- **WHEN** вход по устройству не удался (нет связи, ошибка сервера, лимит)
- **THEN** человек остаётся на экране и видит «Не получилось начать. Попробуй ещё раз» либо общую фразу по статусу

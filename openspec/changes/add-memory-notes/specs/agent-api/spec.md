# Дельта-спецификация: agent-api

## MODIFIED Requirements

### Requirement: Память

Агент SHALL помнить о человеке короткие заметки и SHALL искать по его прошлым разговорам (capability `memory-notes`). Маршруты `/v1/users/{userId}/memory`:

- `GET` — настройки, заметки, лимит, совместимые `mode`, `facts`, `limits.maxFacts`;
- `PUT …/settings {enabled?, sensitiveEnabled?, chatSearchEnabled?, consentVersion?}`;
- `PATCH …/notes/{id} {text}`, `DELETE …/notes/{id}`;
- `POST …/notes/instruction {text}` — «скажи, что поправить или убрать»;
- `DELETE …/notes` и `DELETE` — удалить всю память, настройки не меняются;
- `GET …/notes?since=&kinds=`;
- `GET …/export`.

Прежние маршруты фактов:

- `DELETE …/facts/{id}` удаляет заметку;
- `PATCH …/facts/{id}` с `text` правит заметку, закрепление отвечает `422 MEMORY_ACTION_UNSUPPORTED`;
- `POST …/facts` добавляет заметку через проверки;
- `GET …/changes` отвечает `ready` с пустым списком.

Без включения с версией согласия агент MUST NOT читать память в разговор и MUST NOT писать её. Настройки хранятся в базе агента и переживают перезапуск. Чтение, экспорт, удаление и стирание пользователя MUST работать всегда, в том числе на паузе.

Заметки хранятся в базе агента. Cognee получает только реплики человека из завершённых разговоров, по документу на разговор. Всё, что попадает в заметки, MUST проходить проверки в коде; чувствительное — только с согласием. Источником заметок MUST быть только реплики человека. Данные одного человека MUST NOT попадать другому. Тексты MUST NOT попадать в логи, метрики и тексты ошибок.

Функционал включается флагом `MEMORY_NOTES_ENABLED`. Подробности — `openspec/changes/add-memory-notes/design.md`.

#### Scenario: Включение без согласия

- **WHEN** вызывающая сторона шлёт `PUT …/memory/settings {"enabled": true}` без `consentVersion` у человека без действующего согласия
- **THEN** ответ `422 AGENT_VALIDATION`, память не включается

#### Scenario: Удаление заметки

- **WHEN** вызывающая сторона шлёт `DELETE …/memory/notes/{noteId}` для заметки этого человека
- **THEN** ответ `204`, заметки нет в `GET` и в следующем ходе, а для чужой или несуществующей — `404 NOTE_NOT_FOUND`

#### Scenario: Удалить всю память не выключает её

- **WHEN** вызывающая сторона шлёт `DELETE …/memory`
- **THEN** заметок нет, а настройки и согласие прежние

#### Scenario: Блок памяти в разговоре

- **WHEN** у человека включена память
- **THEN** системная инструкция модели содержит правила памяти, заметки и находки из прошлых разговоров (каждое — если включено); итога прошлого разговора в инструкции нет, без сетевых вызовов на ходу

## ADDED Requirements

### Requirement: Удаление разговора

Агент SHALL предоставлять `DELETE /v1/users/{userId}/dialogs/{dialogId}` с ответом `204`. Чужой и несуществующий диалог — `404`. Удаление убирает сообщения, идентификаторы реплик, итог и документ разговора в Cognee (с производными данными). Заметки, извлечённые из разговора, остаются. Маршрут вызывает шлюз приложения, который затем сбрасывает итог недели человека. Открытый диалог перед удалением завершается, его сокет получает `ended`.

#### Scenario: Удалить завершённый разговор

- **WHEN** вызывающая сторона удаляет завершённый разговор человека
- **THEN** ответ `204`, разговора нет в журнале, его реплик нет в поиске, а заметки из него на месте

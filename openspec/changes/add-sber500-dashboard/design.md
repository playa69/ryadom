## Context

Сервис api не видит ни базу агента, ни Langfuse: у него своя база, а ns `prod` закрыт к `infra`. Агент видит и то, и другое, но его выкат рвёт идущие разговоры. Владелец решил вынести дашборд в отдельный контейнер и namespace, не привязанный к сервисам.

## Goals / Non-Goals

**Goals:**
- Страница и JSON с тремя метриками за 7 дней.
- Доступ по паролю.
- Сервисы agent и api не меняются.

**Non-Goals:**
- Исключение тестовых аккаунтов.
- Фиксация прошлых значений.
- Другие метрики.
- Отдельная роль базы и отдельные ключи Langfuse.

## Decisions

- **Отдельный namespace `dashboard` без istio-сайдкара**, как `infra`.
  - Вход — только от шлюза на :8080, выход — DNS, база на :5432, Langfuse на :3000.
  - В политиках базы и Langfuse по одному разрешению для этого namespace.
  - Пробы — `exec` внутри контейнера, чтобы не открывать вход с узлов.
- **Python, стандартная библиотека и psycopg, один файл.** HTML рисуется на сервере, inline SVG, без JS и CDN.
- **Те же доступы, что у агента.** DSN базы и ключи Langfuse берутся из тех же значений, что у агента. Этого хотел владелец ради простоты: «главное, чтобы лишнее не торчало наружу».
  - Сессия базы только на чтение.
  - Наружу два пути, только суммы.
- **Basic auth в сервисе.** В шлюзе Istio его нет. Ограничение неудачных входов по IP в памяти, IP — из `X-Forwarded-For` шлюза.
- **Кэш в памяти на час.** Пересчёт сразу после смены московских суток. При сбое отдаётся прошлый результат.

## Risks / Trade-offs

- **У контейнера полный доступ к базе агента и Langfuse.** Снаружи видны только два пути с суммами, а сессия базы только на чтение.
- **Пароль простой** (id команды). От перебора защищает ограничение 10 неудачных входов в минуту с IP.
- **История и стирания.**
  - Разговоры до агента 0.8.0 в базу не переносились, поэтому нарастающий итог пользователей начинается с конца октября.
  - Стирания разговоров могут немного уменьшать прошлые значения.

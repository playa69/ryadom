Задача: PROTEUS-299

## Why

Организаторы Sber500 просят дашборд с тремя метриками команды по дням: активные пользователи, вызовы LLM и пользователи. Он нужен для healthcheck стартапов на этой неделе и вместо ручного ежедневного ввода в Batchcamp. Доступ в Langfuse дать нельзя: там открыты тексты разговоров. Поэтому нужна отдельная страница только с агрегатами.

## What Changes

- Новый отдельный сервис `dashboard` в своём namespace. Отдаёт `/dashboard` (графики и таблица) и `/dashboard/api` (JSON) за последние 7 полных суток по Москве.
- Определения команды от 11.11.2026:
  - активные — больше 10 реплик за сутки;
  - пользователи — больше 3 реплик за всё время, нарастающим итогом;
  - вызовы LLM — трассы Langfuse за сутки.

  Тестовые аккаунты не исключаются.
- Вход по basic auth с одной учётной записью для организаторов; неудачные входы ограничены по IP.
- Пересчёт не чаще раза в час; запросы к странице базу и Langfuse не трогают.

## Capabilities

### New Capabilities

- `sber500-dashboard`: дашборд метрик для организаторов Sber500.

### Modified Capabilities

Нет.

## Impact

| Поверхность | Затрагивается |
|---|---|
| agent | нет: сервис только читает его базу и Langfuse |
| api | нет |
| web, pwa, android, ios, tg, admin, landing | нет |

Новое: папка `dashboard/` (Python, стандартная библиотека и psycopg) и `k8s/dashboard/`. Кроме того, по одному разрешению для ns `dashboard` в политиках базы и Langfuse. Миграций нет.

Вне рамок:
- исключение тестовых аккаунтов;
- фиксация прошлых значений (они пересчитываются раз в час);
- история разговоров до агента 0.8.0 (её нет в базе).

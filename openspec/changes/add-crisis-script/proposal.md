## Why

Кризисная ветка сегодня — одна фиксированная фраза и лист с телефонами; детектор ловит пять формулировок (по набору из концепции v1 — около трети случаев), жёлтого уровня, вопроса о безопасности, закреплённой кнопки звонка и возврата после звонка нет. Концепция v1 («Кризисная ветка: скрипт», PROTEUS-279) описывает двухшаговый сценарий по схеме психолога.

## What Changes

- Детектор — две ступени: расширенный словарь (красные и жёлтые слова) и фоновая модель, если словарь промолчал. Сбой модели не отменяет словарь.
- Конечный автомат сценария: красный уровень (шаг 1 → вопрос о безопасности → «112» или закреплённая кнопка → напоминание раз в 4 реплики → возврат после звонка) и жёлтый (прямой вопрос → «да» в красный, «нет» в спокойный разговор с плашкой).
- Фразы скрипта — в одном конфиге `agent/app/services/crisis_script.py`, без обращения по имени и без рода; тесты проверяют запрещённые фразы.
- Пока разговор в кризисе, модель получает спокойную добавку к инструкции: без шуток, советов и упражнений, кроме заземления.
- Кадры: `safety` получает `step`, `pinned`; новый кадр агента `safety_state`; клиентские кадры `safety_call`, `safety_answer`, `safety_return`. Только добавление.
- Клиенты (web, PWA, Android, iOS, Telegram): лист «Сейчас важно поговорить с живым человеком» с кнопкой «Позвонить сейчас», строкой 112 и ссылкой «Я в безопасности, давай продолжим»; закреплённая кнопка звонка; кнопки «Да / Нет / Не знаю»; плашка «Нужна помощь?»; шарик без пульсации.
- Аналитика: событие `crisis_call_pressed` (уровень и источник срабатывания, без человека и без текста), метрики агента `agent_crisis_triggers_total`, `agent_crisis_call_pressed_total`.

Не входит (отдельной задачей): пуш через несколько часов после закрытия приложения (шаг 5 концепции) — в сервере нет отправителя пушей для этого случая; список номеров для людей не из Москвы; ревью психолога и юриста; прозвон номеров перед релизом.

## Capabilities

### Modified Capabilities

- `crisis-safety`: распознавание в две ступени с двумя уровнями, сценарий красного и жёлтого уровня, закреплённая кнопка, возврат после звонка, лист с кнопкой звонка, качество детектора.

## Impact

| Поверхность | Затрагивается | Изменение |
|---|---|---|
| agent | да | Детектор, автомат, конфиг скрипта, метрики, добавка к инструкции |
| api | да | Прокидывание кадров, событие аналитики |
| web, pwa, android, ios, tg | да | Лист, закреплённая кнопка, ответы, плашка, шарик |

**Совместимость.** Контракт растёт только добавлением. Старый клиент не знает `safety_state` и поле `step`: он показывает прежний лист по кадру `safety`, закреплённой кнопки и кнопок ответа у него нет — скрипт при этом работает голосом и текстом.

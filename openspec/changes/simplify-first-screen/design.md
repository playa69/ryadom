## Context

Первый экран сейчас — карточка с тремя флажками и «Начать»; после неё главный экран, окно про память и «Поговорить». Новый вход повторяет главный экран, и первое действие сразу открывает разговор. Запись согласий в API (`POST /api/auth/me/consents`, три флага) и вход по устройству (`POST /api/auth/device`) не меняются.

## Decisions

- **Согласие — само действие.** Клиент шлёт те же три флага `true` при первом действии: вход по устройству с записью согласий уже существует (вход «с согласием»), его и вызывает первый экран. Поэтому API и старые клиенты не затронуты, сервер по-прежнему не начнёт разговор без записанных согласий.
- **Веб.** Первый экран остаётся по адресу `/welcome`, но рисуется во весь экран, как главный, а не карточкой. Нажатие делает то же, что главный экран: старт разговора, передача приветствия и набранного текста экрану разговора, переход на `/dialog/{id}`. Приветствие по времени суток считается только в браузере: на сервере другой часовой пояс, и разметка расходилась бы.
- **Мобильный клиент.** После входа приложение меняет набор экранов (экраны без сессии → вкладки), и переход из первого экрана потерялся бы. Первый экран оставляет одноразовую отметку «начать разговор» и входит; главный экран при появлении забирает её и начинает разговор так же, как своей кнопкой, а окно про память в этот раз не открывает. `unlockSpeech` вызывается в том же нажатии, поэтому приветствие звучит.
- **Ворота новой версии условий** остаются отдельным режимом первого экрана: у вошедшего человека есть история, и заставлять его начинать разговор ради согласия незачем. Флажков нет, под «Продолжить» строка о согласии.
- **Регистрация по почте**: флажков нет, строка под «Создать аккаунт»; согласия записываются после входа по коду, как и раньше.
- **Telegram Mini App**: поле «Как к тебе обращаться» остаётся (оно не добавляет касаний и не отправляется само), кнопка — «Поговорить».
- **Сквозные тесты.** Помощник, который заводит гостя для тестов других функций, больше не проходит первый экран: он кладёт удостоверение устройства, через API заводит аккаунт и записывает согласия, а приложение при запуске входит по этому удостоверению без экранов (поведение знакомого устройства). Первый экран проверяют свои тесты.
- **Аналитика.** Нажатие на первом экране — `cta_clicked` (`start_anonymous`, в Mini App `start_telegram`, `placement: welcome`), исход — `auth_form_submitted` (`device_start`, `telegram_start`), как раньше; воронка «визит → аккаунт → согласия → разговор» считается по-прежнему.

## Risks / Trade-offs

- [Согласие нажатием, без отдельного флажка] → формулировку строки смотрит юрист; документ согласия на сайте пока совпадает с политикой.
- [Человек начинает разговор, не прочитав строку] → строка стоит прямо под полем и кнопкой, ссылки открывают документы; запись согласий та же, что раньше.
- [Окно про память не показано при первом разговоре] → оно покажется на главном экране при следующем заходе, как сейчас для закрывших его.

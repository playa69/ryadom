# Proposal: add-dialog-share-link

## Why

Человек хочет показать близким или специалисту один конкретный разговор: «вот что меня беспокоит». Сейчас единственный путь — скриншоты. Это не вяжется с `REQ-CARE-*` (мост к людям): приложение должно помогать делиться тяжёлым, а не мешать.

Разговоры при этом — самые чувствительные данные продукта (`REQ-PRD-07`, `CON-DATA-*`). Поэтому фича проектируется от приватности: ссылка живёт ограниченное время, открывает ровно один разговор, ничего не пишет, её можно отозвать, а без явного действия владельца разговор недоступен никому.

## What Changes

- **Ссылка на разговор.** Из экрана записи журнала (веб и PWA/мобильный) человек создаёт ссылку на выбранный разговор. Срок жизни — от 24 часов до 7 дней (варианты 24 ч / 3 дня / 7 дней, по умолчанию 24 ч).
- **Публичная страница просмотра** `/app/s/<token>`: только чтение, без входа, без аудио, без сводки и оценок напряжения; страница не индексируется и не кэшируется.
- **Управление ссылками**: список активных ссылок разговора, отзыв в одно действие, автоматическое прекращение действия при удалении разговора, «забыть всё», удалении аккаунта и истечении срока.
- **Бэкенд**: таблица `dialog_shares` в `app/packages/db`, четыре маршрута в `app/services/api`, чтение сообщений у агента (агент остаётся единственным владельцем текстов).
- **Макеты** веб и PWA: `mockups/share-mockups.html` (+ PNG в задаче).
- **Спека**: новая capability `dialog-share`, требование `REQ-DATA-05` и сущность `dialog_shares` в `docs/spec.md`.

Код в этом change'е не меняется: это проектный change (спека, дизайн, макеты, задачи).

## Capabilities

### New Capabilities

- `dialog-share`: создание, просмотр, управление и прекращение действия ссылки на один разговор.

### Modified Capabilities

- `client-journal` (добавляется кнопка «Поделиться» на экране записи) — правится после утверждения дизайна, отдельной дельтой.
- `client-profile` (удаление аккаунта отзывает ссылки) — сценарий добавляется в `dialog-share`, дельта не нужна.

## Impact

- `app/packages/db`: миграция `dialog_shares`.
- `app/packages/contracts/src/api/dialogs.ts`: типы ссылок (только добавление полей и маршрутов).
- `app/services/api`: маршруты, лимиты, отдельный публичный маршрут вне JWT.
- `app/apps/web`, `app/apps/mobile`: кнопка, лист «Поделиться», страница `/app/s/<token>`.
- `agent/`: нужна ручка чтения сообщений диалога по id с границей `upToMessageId` (проверить, есть ли уже `GET /v1/users/{userId}/dialogs/{id}`).
- `k8s/`/ingress: путь `/app/s/` и `/api/shared/` без авторизации, с отдельным лимитом.

# Дельта-спецификация: dialog-share

Остаток change'а на 2026-10-27. Ссылка на разговор уже работает и описана в `openspec/specs/dialog-share`; здесь только то, чего в коде ещё нет.

## ADDED Requirements

### Requirement: Подсказка «Люди рядом» в листе кризисного разговора

Для разговора, в котором сработал кризисный протокол, лист «Поделиться» SHALL перед созданием ссылки показывать мягкую подсказку «Если тебе сейчас плохо — линии помощи «Люди рядом»» со ссылкой на раздел «Люди рядом» (см. capability `crisis-safety`). Подсказка MUST NOT запрещать или откладывать создание ссылки: кнопка «Создать ссылку» остаётся доступной, делиться кризисным разговором можно. Агент SHALL отдавать признак «в разговоре был кризисный сигнал», а API — передавать его клиентам вместе с разговором.

Поверхности: agent · api · web · pwa · android · ios · tg

#### Scenario: Кризисный разговор
- **WHEN** человек открывает лист «Поделиться» для разговора, в котором сработал кризисный протокол
- **THEN** над кнопкой «Создать ссылку» видна подсказка «Если тебе сейчас плохо — линии помощи «Люди рядом»» со ссылкой
- **AND** кнопка «Создать ссылку» активна, ссылка создаётся как обычно

#### Scenario: Обычный разговор
- **WHEN** человек открывает лист «Поделиться» для разговора без кризисного сигнала
- **THEN** подсказки нет

#### Scenario: Переход к линиям помощи
- **WHEN** человек нажимает на ссылку «Люди рядом» в подсказке
- **THEN** открывается раздел «Люди рядом»

#### Scenario: (API) Признак кризиса в данных разговора
- **WHEN** клиент запрашивает разговор, в котором сработал кризисный протокол
- **THEN** в данных разговора признак кризиса установлен, а у разговора без кризисного сигнала — нет

### Requirement: Страницы ссылок закрыты в robots.txt

Файл `robots.txt` сайта SHALL запрещать поисковым роботам страницы ссылок на разговоры (`/s/`, в проде `/app/s/`) в дополнение к заголовку и признаку `noindex` самой страницы (см. «Защита ссылки»). Остальные страницы сайта остаются разрешёнными.

Поверхности: landing · web

#### Scenario: robots.txt
- **WHEN** робот запрашивает `/robots.txt` сайта
- **THEN** путь страниц ссылок запрещён, а остальной сайт разрешён

# Proposal: add-backend-content

## Why

Пятый, завершающий MVP-контур блок backend: контент и «мост к живым людям». Новости держат пользователя в курсе развития продукта; справочник «Люди рядом» (горячие линии, группы, специалисты) — сквозной принцип спеки «успех — когда тебе легче и ты ближе к людям»; фиксация SOS/кризисов нужна для метрик безопасности (recall кризис-классификатора, время до показа помощи, конверсия в контакт).

## What Changes

- **Новости** по docs/openapi.yaml (тег `news`): `GET /news` (cursor-пагинация, фильтр `tag`, лента с teaser), `GET /news/{id}` (полная новость с body_markdown; 404 `NEWS_NOT_FOUND`). Публичные (без обязательной auth). Админ-CRUD — TODO v2, вне scope этого change'а.
- **Справочник «Люди рядом»** (тег `support`): `GET /support/hotlines` (горячие линии — всегда первым блоком на клиенте), `GET /support/groups?topic=` (группы поддержки по типу запроса: addiction/grief/burnout/anxiety/other; без аффилиации с брендами сообществ), `GET /support/specialists?topic=` (проверенные специалисты, партнёрская программа). Кэширование по ETag (`If-None-Match` → 304); auth опционален — справочник доступен и до входа.
- **SOS**: `POST /sos/events` — фиксация нажатия SOS или срабатывания кризис-классификатора (trigger: `sos_button`/`crisis_classifier`), обязательный `Idempotency-Key`, auth опционален (SOS доступен всегда, без auth-блокировки), лимит 10/час по IP, ответ 201 — ресурсы помощи (горячие линии).
- **Модели и миграции**: `news`, `support_resources`, `sos_events`; сидирование справочника и стартовых новостей миграцией.

Зависимости: add-backend-foundation-auth (каркас, идемпотентность, rate-limit по IP); auth — опциональный для всех эндпоинтов change'а. Вне scope: админ-CRUD новостей и справочника (TODO v2), маркетплейс специалистов с бронированием (после конкурса), отправка SOS-уведомлений третьим лицам.

## Capabilities

### New Capabilities

- `content`: публичный контент и «мост к живым людям» — новостная лента, кэшируемый справочник поддержки (линии/группы/специалисты) с ETag, фиксация SOS-событий без auth-блокировки для метрик безопасности.

## Impact

- **Новый код**: `app/services/news_service.py`, `support_service.py`, `sos_service.py`, роутеры `app/api/v1/news.py`, `support.py`, `sos.py`.
- **API**: 6 REST-эндпоинтов (теги `news`, `support`, `sos` в docs/openapi.yaml).
- **БД**: таблицы `news`, `support_resources`, `sos_events`; миграция Alembic + сид-данные справочника.
- **Метрики**: счётчики открытий «Люди рядом», SOS-события по trigger, конверсия в контакт (клиентские события — вне scope).
- **Кэш**: ETag на справочник; нечастые инвалидации при обновлении сид-данных.

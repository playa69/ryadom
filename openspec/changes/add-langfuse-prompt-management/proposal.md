## Why

Все инструкции моделей сейчас зашиты в код агента: чтобы посмотреть или изменить их, нужны выкат и повторное ревью кода. При этом в кластере уже работает Langfuse с Prompt Management, но в нём нет ни одного промпта, а по трассам нельзя определить, какая версия инструкции дала конкретный ответ.

## What Changes

- Все статические инструкции моделей агента переносятся в Langfuse: основной диалог и его части, правила памяти и рода агента, голосовой путь Сбера, дословная озвучка, классификатор тона, итоги разговоров и недели, извлечение и исправление заметок.
- **Текстов промптов в репозитории не остаётся: Langfuse — единственный источник инструкций. Локального резерва в коде и файлах нет.**
- В репозитории остаются только имена 15 промптов и метки их назначения, без содержимого.
- Агент читает в runtime версию с label `production`: создание черновой версии ничего не меняет, а перевод label на другую версию применяет её к новым вызовам и сессиям модели без выката.
- При недоступном Langfuse используется только действующий кэш уже полученной production-версии. Если её нет, модельный вызов завершается ошибкой: пустая или локальная резервная инструкция не подставляется.
- Имя, версия и источник промпта связываются с generation в Langfuse; для фоновых операций создаются собственные трассы, чтобы там тоже было видно применённую версию.
- Первоначальные версии загружаются идемпотентным скриптом из внешнего JSON-файла, который хранится локально у администратора и не попадает в git. Повторная синхронизация не перезаписывает версии, которые администратор уже изменил в Langfuse.
- Детерминированный кризисный протокол, фиксированные фразы интерфейса, проверки ответов, правила приватности, JSON-схемы и числовые параметры моделей остаются в коде и не становятся удалённо редактируемыми промптами.

## Capabilities

### New Capabilities

- `prompt-management`: каталог имён инструкций моделей агента, их версии и labels в Langfuse, применение в runtime, наблюдаемость использованных версий и поведение при недоступном Langfuse.

### Modified Capabilities

Нет: существующие требования к разговору, памяти, итогам, настроению, приватности и API сохраняются; меняется источник инструкций и их наблюдаемость.

## Impact

| Поверхность | Затрагивается | Комментарий |
|---|---|---|
| agent | да | Все вызовы моделей, загрузка инструкций, трейсинг |
| api | нет | Контракт не меняется |
| web | нет | — |
| pwa | нет | — |
| android | нет | — |
| ios | нет | — |
| tg | нет | — |
| admin | нет | Управление ведётся через существующий Langfuse UI, а не админку приложения |
| landing | нет | — |

- Затрагиваются основной диалог, клиенты Gemini Live и Сбера, классификатор тона, итоги, дайджесты и извлечение памяти в `agent/`, а также `k8s/agent/` и документация запуска.
- Используется уже установленный Langfuse Python SDK v3; новой библиотеки и миграции базы приложения нет.
- Требуется одноразовая загрузка начальных версий в существующий Langfuse из внешнего файла без сохранения текстов в репозитории. Других открытых change'ей и миграций БД нет; `add-push-notifications` не пересекается.
- Вне рамок: публичная публикация Langfuse, собственный редактор промптов в админке, A/B-тесты и автоматическая смена labels, изменение моделей и детерминированной логики агента.

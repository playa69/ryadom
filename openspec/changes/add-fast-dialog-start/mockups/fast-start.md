# Быстрый старт разговора

Отдельного предварительного ворота согласия на Web, PWA и Telegram больше нет: новый человек сразу видит главную из макетов ниже, а обязательное согласие появляется окном или листом поверх неё при первой попытке отправить текст или начать голос. На Android и iOS прежний экран согласия сохраняется и здесь не повторяется. Подсказки подставляют текст без запроса. На Android и iOS остаются текущие тёмные экраны без поля и подсказок.

Web, PWA, Telegram и все публичные страницы лендинга (главная и документы) по умолчанию используют местное время устройства: с 07:00 до 21:59 — светлый фон и тёмный текст, с 22:00 до 06:59 — текущая тёмная тема. Компоновка, тексты и действия одинаковы в обеих темах. Открытый клиент или вкладка меняет палитру на границе без перезагрузки и потери черновика, если человек не выбирал тему вручную. Тема выставляется до первой отрисовки, без мигания.

Справа сверху находится компактный переключатель `[день ○—● ночь]`: его можно нажать, провести пальцем или переключить с клавиатуры. Контрол показывает текущую тему — солнце в светлой и светящийся полумесяц в тёмной — и доступен как `switch` с названием следующего действия. Визуальный размер маленький, зона нажатия — не меньше 44×44. На Web он стоит в шапке перед SOS, на лендинге — в правой верхней части каждой публичной страницы. Ручной выбор сохраняется на этом устройстве, не отправляет запрос и дальше не сбрасывается расписанием.

## Web: 390 и 1280

```text
┌──────────────────────────────────────┐
│ Меню   Новый разговор   [○—●]   SOS  │
│                                      │
│               [шар]                  │
│           Добрый вечер               │
│  Я здесь и никуда не спешу.          │
│  О чём хочется сказать?              │
│                                      │
│ [Хочу выговориться] [Мне тревожно]   │
│          [Просто поговорить]         │
│ ┌──────────────────────────────────┐ │
│ │ Напиши или скажи, что на душе…   │ │
│ │                       Говорить → │ │
│ └──────────────────────────────────┘ │
│        Настроить разговор  [+]       │
│                                      │
│ Документы и согласие · 112           │
│ Люди рядом — линии помощи            │
└──────────────────────────────────────┘
```

На 1280 содержимое остаётся центрированной колонкой, подсказки помещаются в одну строку. Сайдбар и шапка сохраняются.

Новый человек видит эту же главную до согласия: ввод текста, выбор подсказки и переключение темы не создают аккаунт, разговор или запрос.

После «Настроить разговор» под композером раскрывается прежний выбор памяти. По умолчанию блок свёрнут.

## PWA и Telegram: 390

```text
┌──────────────────────────────────────┐
│ Рядом              Войти  SOS [○—●]  │
│                                      │
│               [шар]                  │
│           Добрый вечер               │
│  Я здесь и никуда не спешу.          │
│  О чём хочется сказать?              │
│                                      │
│ [Хочу выговориться] [Мне тревожно] ▸ │
│ ┌──────────────────────────────────┐ │
│ │ Напиши, что происходит…          │ │
│ └──────────────────────────────────┘ │
│ [            Поговорить            ] │
│                                      │
│ Настроить разговор  [+]              │
│                                      │
│ Документы и согласие · 112           │
└──────────────────────────────────────┘
```

Новый человек попадает сразу на этот экран, без предварительного ворота. Пустое поле: кнопка «Поговорить» начинает голосовой разговор. После ввода или выбора подсказки: кнопка меняется на «Отправить» и начинает текстовый разговор. Поле принимает до 4000 знаков; Enter отправляет, Shift+Enter добавляет строку.

Подсказки — компактные чипы по ширине содержимого в одной горизонтально прокручиваемой ленте: без переноса на три строки и без кнопок на всю ширину, с небольшими отступами между лентой и полем. «Просто поговорить» доступна прокруткой ленты; лента доступна с клавиатуры и не прокручивает страницу по горизонтали.

«Настроить разговор» — доступный нативный `details/summary`, свёрнутый по умолчанию, как на Web; он не конкурирует с полем и кнопкой «Поговорить». Внутри — прежний выбор памяти без изменений:

```text
Настроить разговор  [−]
  Запоминать важное          [switch]
  описание, согласие на память, ошибки
```

Шапка на 390: переключатель темы, SOS и «Войти» видны целиком и не перекрывают друг друга.

## Подсказка выбрана

```text
[Хочу выговориться] [Мне тревожно] ▸
┌──────────────────────────────────┐
│ Мне тревожно|                    │
└──────────────────────────────────┘
[             Отправить            ]
```

Лента подсказок остаётся одной прокручиваемой строкой и после выбора. Текст можно изменить. До «Отправить» нет аккаунта, диалога или запроса.

## Окно согласия поверх главной (Web)

```text
┌──────────────────────────────────────┐
│ ░ главная затемнена, за окном ░      │
│ ░ черновик «Мне тревожно»       ░    │
│  ┌────────────────────────────────┐  │
│  │ Перед началом               ✕  │  │
│  │ Один раз подтверди, что        │  │
│  │ согласен(на), — и можно        │  │
│  │ говорить                       │  │
│  │ ☐ Мне есть 18 лет, я принимаю  │  │
│  │   условия использования и даю  │  │
│  │   согласие на обработку        │  │
│  │   персональных данных          │  │
│  │ [   Продолжить (неактивна)   ] │  │
│  └────────────────────────────────┘  │
└──────────────────────────────────────┘
```

Окно открывается при «Отправить», Enter, «Поговорить» или микрофоне, если согласие ещё не записано. Флажок по умолчанию снят, «Продолжить» неактивна до отметки. Ссылки ведут на условия и согласие и не закрывают окно.

## Лист согласия (PWA и Telegram)

```text
┌──────────────────────────────────────┐
│ ░ главная, за листом черновик ░      │
│ ╭──────────────────────────────────╮ │
│ │ Перед началом                    │ │
│ │ Один раз подтверди, что          │ │
│ │ согласен(на), — и можно говорить │ │
│ │ ☐ Мне есть 18 лет, я принимаю    │ │
│ │   условия использования и даю    │ │
│ │   согласие на обработку          │ │
│ │   персональных данных            │ │
│ │ [   Продолжить (неактивна)     ] │ │
│ ╰──────────────────────────────────╯ │
└──────────────────────────────────────┘
```

Тот же состав и правила, что у окна на Web; лист поднимается снизу.

## Закрытие и продолжение

Esc, нажатие на фон, крестик или жест «назад» закрывают окно или лист: запрос не отправляется, аккаунт и разговор не создаются, черновик и намерение (текст или голос) остаются на главной. После отметки флажка «Продолжить» становится активной; её нажатие автоматически продолжает исходное действие: при необходимости создаётся аккаунт, записываются согласия, начинается разговор — набранный текст уходит один раз либо начинается голосовой разговор. Ошибка оставляет человека на главной с черновиком и сообщением; повтор не открывает окно заново. Согласие на память («Запоминать важное») остаётся отдельным и в окно не входит.

## Первый текстовый диалог

```text
┌──────────────────────────────────────┐
│ Разговор                             │
│                                      │
│ Агент: Я рядом. С чего начнём?       │
│                                      │
│                 Вы: Мне тревожно     │
│                    (доставляется)    │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ Напиши, что происходит…       →  │ │
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

Микрофон и озвучка сами не включаются. При обрыве сообщение остаётся одним и доставляется существующей очередью. После ошибки старта человек остаётся на прежнем экране с черновиком и сообщением об ошибке.

## Дневная и ночная палитры

```text
День, 07:00–21:59             Ночь, 22:00–06:59
┌──────────────────────┐      ┌──────────────────────┐
│ светлый фон          │      │ тёмный синий фон     │
│ тёмный текст         │      │ светлый текст        │
│ [шар]                │      │ [шар]                │
│ [подсказки]          │      │ [подсказки]          │
│ ┌──────────────────┐ │      │ ┌──────────────────┐ │
│ │ белое поле       │ │      │ │ тёмное поле      │ │
│ └──────────────────┘ │      │ └──────────────────┘ │
│ [ синее действие   ] │      │ [ синее действие   ] │
└──────────────────────┘      └──────────────────────┘
```

Меняются только цветовые токены фона, поверхностей, текста, границ, теней и атмосферы. Синий основной кнопки и красный SOS сохраняют одинаковый смысл. Окно и лист согласия следуют текущей теме. Контраст текста — не ниже 4.5:1, границ контролов — не ниже 3:1. Для проверки снимаются одинаковые состояния в обеих темах на 390 и 1280.

## Лендинг: день и ночь

Все публичные страницы лендинга — главная и документы — получают ту же тему по местному времени и тот же переключатель справа сверху, что и клиенты: содержимое, тексты и поведение страниц не меняются, меняются только цветовые токены. Ручной выбор общий с клиентами на этом устройстве. Для проверки снимаются главная и страницы документов на 390 и 1280 в светлой и тёмной темах, включая переключатель до и после ручного выбора.

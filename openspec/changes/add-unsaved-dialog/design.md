# Design: add-unsaved-dialog

## Context

Режим «Без памяти» на проде не удалял разговоры через 24 часа и не отражал, что человек хочет не оставлять следа вообще. Решением владельца он заменён галочкой «Не сохранять этот разговор».

## Decisions

### D1. «Не сохранять этот разговор»

Заменяет режим «Без памяти» и срок «24 часа», который был только на бумаге. Галочка выбирается **до начала** разговора и после старта не меняется. Работает при включённой и выключенной памяти. На проводе остаётся прежнее поле `memory: "off"` (чтобы закэшированная PWA не ломалась); смысл другой: разговор не сохраняется.

Для такого разговора:

- **в базу ничего не пишется:** ни реплик, ни итога, ни заметок, ни `model_usage`; живой диалог существует только в памяти процесса агента, пока идёт разговор;
- нет блока памяти, заметок, итога, документа в Cognee, поиска по нему;
- в продуктовую аналитику попадает только факт начала и конца без содержания (как у обычного, без `dialog_id`);
- при перезапуске агента (выкат) разговор теряется: клиент показывает «Разговор не сохранён», пометки в журнале нет;
- когда разговор закончился штатно, в `dialogs` пишется **строка-пометка** без текста: `id`, человек, начало, конец, `memory_mode='off'`, без сообщений. В журнале это «Был разговор, который не сохранён по твоему желанию» (дата, время, длительность). Пометка подчиняется сроку хранения (`add-mood-diary`, D14) и удаляется вручную («Удалить разговор»);
- кризисная защита (`safety`, SOS, подсказки помощи) работает как в обычном разговоре и от сохранения не зависит, в базу кризисные куски не пишутся;
- недельные итоги о нём ничего не знают.

**Перед началом разговора.** Рядом с кнопкой «Поговорить» стоит галочка «Не сохранять этот разговор» с подсказкой «Он не попадёт в журнал, итоги и память». Её нельзя поменять после начала.

## Границы с соседними change'ами

- `add-memory-notes`: своих требований по этому режиму нет; исключение из заметок и Cognee следует из требования «Что не сохраняется» этого change'а.
- `add-mood-diary`: итог не считается, недельные итоги о нём не знают, пометка в журнале показывается записью без текста (задача 3.10), пометка подчиняется сроку хранения (D14).

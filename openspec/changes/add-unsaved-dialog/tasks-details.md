# Подзадачи: «Не сохранять этот разговор» (add-unsaved-dialog)

### 1.1 Агент: «Не сохранять этот разговор»

#### Что сделать
Разговор с `memory: off` (галочка до начала, `design.md`, D1) живёт только в памяти процесса агента: ни сообщений, ни итога, ни заметок, ни `model_usage` в базе, нет блока памяти, документа в Cognee, поиска и продуктовой аналитики. После штатного завершения в `dialogs` пишется строка-пометка без текста (она подчиняется сроку хранения, `add-mood-diary` 2.14). При перезапуске агента такой разговор теряется (клиент показывает «Разговор не сохранён»). Кризисная защита работает как обычно.

#### Приёмка
- Сценарии «Ничего не сохраняется», «Перезапуск агента», «Память выключена», «Кризис в несохраняемом разговоре» из `specs/unsaved-dialog/spec.md`.
- Требование «Разговор без памяти» из `specs/agent-api/spec.md`.

### 1.2 Агент: не сохраняемый разговор не попадает в память

#### Что сделать
Охранники уже есть в коде памяти из `add-memory-notes` (ветка PROTEUS-242): в `agent/app/memory/cognee_backend.py` для разговора с `memory_mode` не `on` блок памяти пуст (`brief`), заметки не извлекаются (`_notes_active`), индексация в `memory_outbox` не ставится (`dialog_ended`); пересборка индекса берёт только разговоры с `memory_mode = 'on'` (`indexable_dialog_ids` в `agent/app/services/dialog_db.py`). Там же есть частичные тесты. Здесь: сослаться в коде на требование «Не сохраняемый разговор не попадает в память» и добавить тест его сценария. После 1.1 (разговор живёт только в памяти процесса) охранники должны действовать так же.

#### Приёмка
- Сценарий «Память и поиск включены» требования «Не сохраняемый разговор не попадает в память» из `specs/unsaved-dialog/spec.md`: тест агента проверяет, что по разговору нет заметок, документа в Cognee и записей в `memory_outbox`, а пересборка индекса его не берёт.

### 2.1 Клиенты: галочка «Не сохранять этот разговор»

#### Что сделать
- Галочка «Не сохранять этот разговор» (подсказка «Он не попадёт в журнал, итоги и память») рядом с кнопкой «Поговорить» на главной и в дневнике: при выборе начало диалога уходит с `memory: "off"`. После старта не меняется. При потере разговора из-за перезапуска агента — «Разговор не сохранён».

#### Приёмка
- Сценарии «Ничего не сохраняется», «Перезапуск агента» из `specs/unsaved-dialog/spec.md`.

### 3.1 Мок агента и e2e

#### Что сделать
Мок агента `app/dev/agent-mock/server.mjs`: режим `memory: "off"` без следа, пометка после завершения. e2e: разговор с галочкой не оставляет реплик, заметок, находок и итога; в журнале пометка без текста.

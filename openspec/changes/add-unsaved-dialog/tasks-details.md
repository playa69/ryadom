# Подзадачи: «Не сохранять этот разговор» (add-unsaved-dialog)

### 1.1 Агент: «Не сохранять этот разговор»

#### Что сделать
- `POST /v1/users/{id}/dialogs` принимает `saved` (по умолчанию `true`), ответ, журнал и запись отдают `saved`.
- Разговор с `saved: false` живёт только в памяти процесса: в базу не уходят ни реплики, ни идентификаторы клиента, ни `model_usage`; в память агента он не сообщается. Память у него всегда `off`.
- Завершение (кнопка, кадр `end`, автозавершение брошенного) удаляет текст из памяти процесса и пишет одну строку-пометку (колонка `dialogs.saved`, идемпотентный `ADD COLUMN IF NOT EXISTS`). Итога нет; «что забираешь с собой» и напряжение не сохраняются.
- Пока разговор идёт, человека не выгружают из памяти пода. После перезапуска он теряется (сокет — `404`).
- `recaps.eligible` смотрит на `saved`, а не на `memory_mode`: у разговора «Без памяти» итог теперь есть.
- Убрать из кода и комментариев обещание «удалится через 24 часа» и причину выгрузки `memory_off`.

#### Приёмка
- Сценарии «Ничего не сохраняется», «Перезапуск агента», «Память выключена», «Кризис в несохраняемом разговоре» из `specs/dialog/spec.md`.
- Тесты агента: `tests/test_unsaved_dialog.py`.

### 1.2 Агент: не сохраняемый разговор не попадает в память

#### Что сделать
Охранники по `memory_mode` в коде памяти уже есть (`agent/app/memory/cognee_backend.py`: `brief`, `prepare`, `_notes_active`, `dialog_ended`; `indexable_dialog_ids` и `dialog_for_index` в `agent/app/services/dialog_db.py`). Здесь: ссылки на требование «Не сохраняемый разговор не попадает в память» в коде, охранник на `user_message` (реплика такого разговора не идёт в поиск по Cognee, иначе находка по ней оседает в сводке следующего разговора), `saved` в запросах индекса, тест сценария.

#### Приёмка
- Сценарий «Память и поиск включены» требования «Не сохраняемый разговор не попадает в память» из `specs/memory-notes/spec.md`: `tests/test_memory_unsaved_dialog.py` проверяет, что по разговору нет заметок, документа в Cognee и записей в `memory_outbox`, поиск по Cognee по его репликам не идёт, а пересборка индекса его не берёт.

### 2.1 Шлюз API

#### Что сделать
- Контракты (`packages/contracts`): `saved?: boolean` в `StartDialogApiRequest`, `saved: boolean` в `StartDialogApiResponse`, код закрытия `DialogGone`.
- `routes/dialogs`: поле `saved` в теле старта, в ответ; ядро (`packages/core`): `saved` в запросе агенту и в ответе старта, в DTO записи и списка (уже есть).
- Аналитика: `dialog_started`, `dialog_turn`, `dialog_ended`, `dialog_interrupted`, `component_called` не отправляются по не сохраняемому разговору (шлюз берёт признак из кадра `ready` агента, REST `…/end` — из ответа агента).
- Ссылка «Поделиться» на такой разговор: `DIALOG_NOT_FOUND`.
- Рукопожатие с агентом, закончившееся `404`, — клиенту `error` `DIALOG_NOT_FOUND` и закрытие `DialogGone`.

#### Приёмка
- Тесты `packages/core` (ядро) и `services/api` (маршрут, шлюз сокета).

### 3.1 Клиенты: галочка «Не сохранять этот разговор»

#### Что сделать
- Галочка «Не сохранять этот разговор» (подсказка «Он не попадёт в журнал, итоги и память») рядом с кнопкой «Поговорить» на главной: веб и PWA (Mini App — та же сборка). Видна всегда. При выборе старт уходит с `saved: false`, после старта не меняется и со следующим разговором снимается.
- Плашка «Не сохраняется» в разговоре вместо «Без памяти», без кнопки памяти и «Поделиться»; лист завершения без полей итога; события экрана разговора не отправляются.
- Потеря разговора: «Разговор не сохранён» с кнопкой «На главную».
- `dialogMemoryMark` для не сохранённого не возвращает «Без памяти».

#### Приёмка
- Сценарии «Выбор перед стартом», «Выбор после старта», «Перезапуск агента» из `specs/dialog/spec.md`.

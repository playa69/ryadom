# Дельта-спецификация: agent-api

## MODIFIED Requirements

### Requirement: Разговор без памяти

Диалог, начатый с `memory: "off"` («Не сохранять этот разговор»), MUST NOT записываться в базу (ни сообщения, ни итог, ни заметки, ни `model_usage`), MUST NOT получать блок памяти, MUST NOT попадать в поиск по прошлым разговорам и в Cognee. Состояние живого диалога MUST храниться только в памяти процесса; перезапуск агента его теряет. После штатного завершения агент SHALL записать строку-пометку без текста (`id`, человек, начало, конец, `memoryMode: off`), которая подчиняется сроку хранения. Журнал и история отдают поле `memoryMode`. Кризисный путь работает как обычно. Значение поля `memory` на проводе прежнее ради совместимости клиентов.

#### Scenario: Ничего не пишется в базу

- **WHEN** идёт разговор с `memory: "off"` и человек успел сказать несколько реплик
- **THEN** в таблицах `dialogs` и `messages` нет строк этого разговора, пока он не завершён, а после завершения есть только строка-пометка без сообщений

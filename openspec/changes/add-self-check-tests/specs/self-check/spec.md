# Дельта-спецификация: self-check

В базе `openspec/specs/self-check` уже есть каталог из одиннадцати тестов, прохождение, подсчёт, результат без диагнозов, экран помощи при кризисном ответе, сохранение результата с согласием, последний результат, историю и динамику, удаление результатов, отзыв согласия, запрет передавать результаты агенту и в аналитику и анонимный счёт кризисных ответов — в вебе и в мобильном клиенте. Эта дельта добавляет то, чего в коде нет: клинические скрининги (волна 3) отдельной группой и экран-предупреждение перед ними. Требования продукта — `REQ-WELL-06`…`REQ-WELL-08` в `docs/spec.md`, решения — `design.md`. Если волну 3 не делаем, этот файл удаляется целиком.

## MODIFIED Requirements

### Requirement: Сегмент «Тесты»

Сегмент «Тесты» SHALL показывать подпись «Опросники, которыми пользуются специалисты. Это скрининг, а не диагноз.», поле «Поиск по названию и коду» и карточки всех тестов: название и код, вводная фраза теста, строку «<код> · N вопросов · ~M мин» и «Пройти →»; у теста с сохранённым результатом карточка показывает его строку и «История» (см. «Последний результат в «Самопроверке»»). Поиск отбирает тесты, в названии, коде, подзаголовке или вводной фразе которых есть введённый текст (без учёта регистра); если ничего не нашлось, показывается «Ничего не нашлось. Попробуй другое слово.». Клинические скрининги (волна 3, если они есть в каталоге) показываются отдельной группой «Для разговора со специалистом» после остальных карточек, поиск действует и на них.

Поверхности: web · pwa · android · ios · tg

#### Scenario: Поиск
- **WHEN** человек вводит «тревог» в поиске каталога
- **THEN** в списке остаются тесты, в названии, коде, подзаголовке или вводной фразе которых есть «тревог»

#### Scenario: Поиск по коду
- **WHEN** человек вводит «k6» в поиске каталога
- **THEN** в списке остаётся «Общее напряжение»

#### Scenario: Ничего не найдено
- **WHEN** поисковому слову не соответствует ни один тест
- **THEN** показано «Ничего не нашлось. Попробуй другое слово.»

#### Scenario: Открытие теста из каталога
- **WHEN** человек нажимает «Пройти →» на карточке «Самооценка»
- **THEN** открывается окно теста с «Вопрос 1 из 10»

#### Scenario: Клинические скрининги отдельной группой
- **WHEN** в каталоге есть клинические скрининги и человек открывает сегмент «Тесты»
- **THEN** они показаны после остальных тестов под заголовком «Для разговора со специалистом»

## ADDED Requirements

### Requirement: Предупреждение перед клиническим скринингом

Перед тестами волны 3 (клиническими скринингами) клиент SHALL показывать экран с пояснением: опросник используют специалисты для первичного скрининга, результат не ставит диагноз, при тревожном результате стоит обратиться к специалисту. Тест начинается только по кнопке «Начать». Для опросников с вопросами о насилии и суициде (ACE) экран SHALL предупреждать, что вопросы могут быть тяжёлыми, и предлагать «Люди рядом». Кризисные пункты клинических скринингов (PCL-5 пункт 16, вопрос ACE о суициде в семье) ведут к тому же экрану помощи, что PHQ-9 пункт 9.

Поверхности: web · pwa · android · ios · tg

#### Scenario: Клинический скрининг
- **WHEN** человек открывает клинический скрининг, например PCL-5
- **THEN** сначала экран с пояснением, тест начинается только по «Начать»

#### Scenario: Тест ACE
- **WHEN** человек открывает тест ACE
- **THEN** сначала экран-предупреждение о тяжёлых вопросах с кнопками «Начать» и «Люди рядом»

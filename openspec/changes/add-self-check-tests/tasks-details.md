## Этап 4. Клиенты

### 4.6 Группа клинических скринингов и предупреждение

#### Что сделать
Перед тестами волны 3 — экран с пояснением: опросник используют специалисты для первичного скрининга, результат не ставит диагноз, при тревожном результате стоит обратиться к специалисту.

# Design: add-self-check-tests

## Context

В приложении нет ни опросников, ни их результатов, ни данных о здоровье. Единственная шкала — напряжение 1–10 в листе завершения разговора. Метрика продукта «динамика WHO-5 за 4 недели» (`docs/spec.md` §9.2) не собирается. В `openspec/changes/add-backend-journal-rituals-checkins` описан чекин `who5` для `backend/`, но приложение `backend/` не вызывает (Q-02). Этот change переносит тесты в `app/services/api` и расширяет их до каталога.

Место в интерфейсе задаёт `add-mood-diary`: блок «Самопроверка» в сегменте «Дневник» и сегмент «Тесты».

## Goals / Non-Goals

**Goals**

- Пройти любой тест каталога внутри приложения на любой платформе, в том числе без сети.
- Увидеть результат как у конкурента: балл, уровень, шкала, оговорка.
- По желанию сохранить результат и видеть динамику.
- Получить помощь сразу, если ответы говорят о риске.
- Каталог расширяется данными, а не новым кодом экранов.

**Non-Goals**

- Статьи и материалы о расстройствах.
- Рекомендации лечения, «вам нужен психиатр», любые диагнозы.
- Передача результатов агенту или в разговор. Обсудить результат с Рядом человек может только сам, рассказав.
- Платный доступ к динамике.
- Собственные авторские тесты без валидации (у конкурента это, вероятно, ОКР, ПРЛ, РПП, ревность и кризис среднего возраста по 15 и 11 вопросов).

## Decisions

### D1. Тест — это данные

Описание теста — объект в `app/packages/self-check/src/tests/<id>.ts`:

```ts
{
  id: 'phq9', version: 1, code: 'PHQ-9',
  title: 'Подавленность', subtitle: 'PHQ-9 · 9 вопросов · ~3 мин', icon: 'cloud-rain',
  preface: 'Как часто за последние 2 недели вас беспокоило следующее?',
  options: [{ label: 'Ни разу', value: 0 }, …],
  items: [{ text: '…', reverse?: false, crisis?: false }, …],
  scoring: { kind: 'sum', multiplier?: 1, max: 27 }
        | { kind: 'mean', subscales: [...] }
        | { kind: 'count', rule: … },
  bands: [{ from: 0, to: 4, label: 'минимальная выраженность', tone: 'calm', text: '…' }, …],
  highBandFrom?: 20,
  source: 'Pfizer, официальный перевод «Russian for Russia»; валидизация Золотарева, 2023',
  license: 'Без разрешения: воспроизведение и перевод разрешены правообладателем',
  status: 'ready' | 'review' | 'blocked',
}
```

Тест показывается в продакшене только со статусом `ready`. Статус ставит владелец, когда закрыты лицензия, текст и ревью.

Функции `score(test, answers)` и `band(test, score)` не имеют побочных эффектов. Тесты подсчёта сверяются с примерами из первоисточника: обратные пункты, множители, подшкалы.

Версия описания растёт при любой правке вопросов или порогов. Результат хранит версию, и история показывает пометку, если версии разные.

### D2. Прохождение — лист, как у конкурента

**Лист.** Мобильный клиент — `Sheet` Framework7, веб — `Modal.tsx` (лист снизу на узком окне). В листе:

- шапка: значок, название, строка «WHO-5 · 5 вопросов · ~1 мин», «×»;
- полоса прогресса и «Вопрос N из M» цветом акцента;
- вводная фраза инструмента;
- текст вопроса;
- варианты ответа — крупные кнопки во всю ширину, касание сразу ведёт к следующему вопросу;
- «← Назад» со второго вопроса, ответ сохраняется.

**Закрытие.** «×» или системное «назад» при трёх и больше ответах спрашивает «Прервать тест? Ответы не сохранятся.» Ответы не уходят на сервер, пока человек не нажал «Сохранить».

**Обращение.** Тексты вопросов — дословно из опубликованной русской версии (часто на «вы»). Тексты интерфейса — на «ты», как во всём приложении.

### D3. Результат

**Лист результата:**

- заголовок «Результат»;
- крупно «15 / 25», для подшкал — строка на каждую;
- уровень цветом его тона;
- шкала из сегментов по числу порогов с отметкой балла;
- 1–2 предложения пояснения;
- оговорка «Это скрининговый опросник, а не диагноз. Если результат тебя беспокоит — обсуди его со специалистом.»;
- кнопки «Закрыть» и «Сохранить».

**Без диагнозов.** Подписи уровней описывают выраженность («лёгкая», «умеренная», «выраженная»), а не болезнь. Нельзя писать «у тебя депрессия» и «депрессия средней тяжести» (`CON-LAW-01`).

**Высокие уровни.** При уровне от `highBandFrom` под пояснением показывается карточка «Поговорить со специалистом» со ссылкой на «Люди рядом».

**Пороги.** Где официальных порогов нет (PSS-10, CBI, Розенберг, UCLA, PSWQ), подпись уровня заменяется строкой «ориентир по данным исследований», без слов «норма» и «отклонение».

### D4. Кризисные ответы

У пункта описания может стоять `crisis: { from: n }`:

- PHQ-9, пункт 9, ответ от 1;
- PCL-5, пункт 16, ответ от 3;
- ACE — вопрос о попытке суицида в семье, ответ «да».

Если хоть один такой пункт сработал, после последнего вопроса **до** результата показывается экран помощи.

- **Заголовок:** «Ты отметил(а), что бывают мысли о смерти или о том, чтобы навредить себе» (для PHQ-9). Для других пунктов текст свой.
- **Текст:** «С этим не нужно справляться одному. Если тяжело прямо сейчас — позвони, это бесплатно и анонимно».
- **Кнопки:** «Позвонить» открывает лист SOS (`client-support`), «Поговорить с Рядом», «Посмотреть результат».

Экран нельзя пропустить молча, только одной из этих кнопок. Сохранение результата на него не влияет. Тексты проходят ревью консультантов (`CON-ETH-04`).

Факт кризисного ответа не попадает в продуктовую аналитику и не связывается с человеком. Считается только `self_check_crisis_total{test}` в Prometheus.

### D5. Сохранение — только баллы, с отдельным согласием

**Первое сохранение** открывает лист согласия:

> Сохранить результаты? Результаты тестов — сведения о самочувствии. Мы храним их на серверах в России, видишь их только ты, Рядом (ИИ) их не читает. Удалить можно в любой момент.

Кнопки «Сохранить» и «Не сохранять». Согласие пишется в `user_consents(kind='self_check', version)`. Без него `POST /api/self-check/results` отвечает `403 CONSENT_REQUIRED`.

**Что уходит на сервер.** Клиент отправляет ответы. Сервер пересчитывает балл тем же пакетом, проверяет версию и сохраняет **только** балл, баллы подшкал, уровень и время. Сами ответы не хранятся и не пишутся в журналы.

**История:**

- в «Самопроверке» под названием теста строка последнего результата «19 октября: 15/25 — умеренное благополучие» с точкой цвета уровня;
- экран теста: история списком и график по датам на SVG, начиная с двух результатов;
- удаление одного результата и «Удалить все результаты тестов» (там же и в профиле, раздел «Данные»).

Удаление аккаунта стирает результаты до объявления удаления. Отзыв согласия удаляет все результаты.

### D6. Каталог и волны

Источник данных о лицензиях — проверка 24.10.2026 по сайтам правообладателей. Это не юридическое заключение, условия каждого «нужно разрешение» и «подтвердить» закрываются письмом правообладателя.

**Волна 1 — «Самопроверка», как у конкурента**

|---|---|---|---|---|---|
| Тревога | GAD-7 | 7 | свободно ([phqscreeners.com](https://www.phqscreeners.com/select-screener)) | официальный перевод Pfizer; валидизация Золотарева, 2023 | можно делать |
| Подавленность | PHQ-9 | 9 | свободно (там же) | официальный перевод Pfizer; валидизация Золотарева, 2023 | можно делать, пункт 9 кризисный |
| Самооценка | шкала Розенберга | 10 | public domain (UMD) | Золотарева, 2020 | можно делать |
| Благополучие | WHO-5 | 5 | CC BY-NC-SA 3.0 IGO: коммерческое использование только с разрешения ВОЗ ([who.int](https://www.who.int/publications/m/item/WHO-UCN-MSD-MHE-2024.01)) | в списке переводов ВОЗ русского нет | запросить разрешение и проверенный перевод |
| Стресс | PSS-10 | 10 | коммерческое использование — разрешение и плата через Mapi ([CMU](https://www.cmu.edu/dietrich/psychology/stress-immunity-disease-lab/scales)) | Абабков и др., 2016 | запросить разрешение |
| Выгорание | CBI, подшкала «личное выгорание» | 6 | заявления правообладателя (NFA, Дания) не нашли | валидизации общей версии не нашли | подтвердить лицензию, перевод с ревью |

**Волна 2 — неклинические опросники каталога «Тесты»**

|---|---|---|---|---|---|

| Привязанность в отношениях | ECR-RS (вместо 17-пунктового теста конкурента, его источник не опознан) | 9 | про коммерцию ничего не сказано, запросить у автора | ECR-RS-Rus, Сабельникова, Каширский | запросить разрешение |

|---|---|---|---|---|

| Внимание и импульсивность | ASRS v1.1, скринер | 6 | разрешено, в том числе коммерчески, с атрибуцией, текст без изменений | официальный перевод Harvard NCS |

| ОКР, ПРЛ, РПП | подобрать валидизированный короткий инструмент (например, OCI-R, MSI-BPD, SCOFF) | — | не проверялось | отдельная проверка лицензий |

Перед каждым тестом волны 3 показывается экран «Этот опросник используют специалисты для первичного скрининга. Результат не ставит диагноз…» с кнопкой «Начать».

Порядок карточек в каталоге: сначала волны 1 и 2, затем волна 3 в группе «Для разговора со специалистом». Поиск по названию, коду и словам из описания.

### D7. Без сети

Описания тестов вшиты в клиентский бандл и входят в предкэш PWA. Пройти тест и увидеть результат можно без сети. Если «Сохранить» не прошло, лист остаётся открытым с «Не получилось сохранить. Повторить». Очереди сохранений нет: результат с чужого устройства в очереди не нужен.

| Событие | Свойства |

| `self_check_searched` | `found` |
| `self_check_started` | `test_id`, `from` |
| `self_check_step_back` | `test_id` |
| `self_check_interrupt_choice` | `test_id`, `action`, `progress` |
| `self_check_completed` | `test_id` |

| `self_check_consent_shown`, `self_check_consent_choice` | `action` |

## Данные и API

```text
self_check_results(id uuid pk, user_id fk users, test_id text, test_version int,
                   score numeric, subscores jsonb null, band text, taken_at timestamptz,
                   created_at timestamptz)
  index (user_id, test_id, taken_at desc)
```

| Маршрут | Описание |
|---|---|
| `GET /api/self-check/results?testId=&before=` | история, новые сверху |
| `GET /api/self-check/latest` | последний результат по каждому тесту, для «Самопроверки» |
| `POST /api/self-check/results` `{testId, testVersion, answers, takenAt}` | `201 {id, score, subscores, band}`; `403 CONSENT_REQUIRED`, `422` при неверных ответах или неизвестной версии |
| `DELETE /api/self-check/results/{id}`, `DELETE /api/self-check/results` | `204` |
| `POST /api/self-check/consent` `{version}`, `DELETE /api/self-check/consent` | согласие; отзыв удаляет результаты |

## Risks / Trade-offs

- **[Клинические скрининги в приложении самоподдержки читаются как диагностика]** Волна 3 только после ревью, подписи без названий болезней, экран-предупреждение, путь к специалисту.
- **[Лицензии]** Статус `ready` выставляется только после подтверждения. Каталог честно показывает меньше тестов, чем у конкурента, пока разрешения не получены.
- **[Метрика WHO-5]** Если ВОЗ откажет, метрика «динамика WHO-5» в `docs/spec.md` §9.2 заменяется. Например, SWLS или свободной шкалой благополучия. Решает владелец.
- **[Пункт 9 PHQ-9 срабатывает часто]** Это и есть цель: экран помощи короткий, не блокирует, не сообщает никому и не меняет разговор.

## Migration Plan

1. Пакет `self-check` и подсчёт с тестами — без интерфейса.
2. Миграция `0010_self_check`, маршруты, вид согласия.
3. Клиенты за флагом `SELF_CHECK_ENABLED` (часть сегментов дневника).
4. Включение тестов по одному, по мере статуса `ready`.
5. Откат — флаг. Сохранённые результаты остаются у людей и снова видны после включения.

## Open Questions

1. **Названия тестов.** У конкурента «Депрессия», «Тревожность». Предлагаем «Подавленность», «Тревога»: в названии нет болезни, а люди найдут тест по коду и описанию. Нужно решение владельца.
2. **Волна 3.** Делаем ли её вообще: принцип «без диагнозов» против полной повторяемости каталога конкурента.
3. **WHO-5 и PSS-10.** Платим и просим разрешение или заменяем свободными шкалами.
4. **Согласие на хранение результатов.** Текст и версия от юриста. Достаточно ли согласия в листе, или нужен отдельный документ.
5. **Предлагать ли тест в дневнике.** Например, WHO-5 раз в две недели для метрики продукта. По умолчанию — нет, только по желанию человека.

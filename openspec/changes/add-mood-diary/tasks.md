# Tasks: add-mood-diary

Контракт — `specs/{mood-diary,mood-reminders,mood-widget,client-shell}/spec.md`. Решения — `design.md` (D1–D12). Требования продукта — `REQ-WELL-*` в `docs/spec.md`. Зависимости:
- **Итоги разговоров** (сегмент «Итоги») — `add-memory-notes`, D7. Итог разговора от варианта памяти не зависит и может выйти отдельной задачей.
- **События недели** — заметки памяти из `add-memory-notes`. Решение по памяти (заметки или только переключатель) ещё не принято. Если выберут переключатель, блок «События недели» строится запросом к Cognee или откладывается.
- **Блок «Самопроверка» и сегмент «Тесты»** — `add-self-check-tests`.

Пока зависимости не готовы, сегменты показывают пустые состояния, а итоги недели строятся только по отметкам.

# Tasks: add-mood-diary

Контракт — `specs/{mood-diary,dialog-recaps,mood-widget,client-shell,agent-api}/spec.md`. Решения — `design.md` (D1–D14). Требования продукта — `REQ-WELL-01`…`REQ-WELL-05`, `REQ-WELL-09` в `docs/spec.md`. Напоминание о настроении и все уведомления — `add-notifications`. Итоги разговоров, журнал и лист завершения — здесь (`dialog-recaps`, D13); из `add-memory-notes` дневник ничего не берёт (блока «События этой недели» нет). «Самопроверка» и «Тесты» — `add-self-check-tests`: блок и сегмент есть всегда. Журнал (история разговоров) входит в «Дневник» сегментом; «Год в пикселях» и «Итоги года» сняты решением владельца (приложению два месяца), см. «Позже» в `design.md`. Пока зависимости не готовы, блоки показывают пустые состояния, а итоги недели строятся только по отметкам. Подробности каждой задачи — `tasks-details.md`.

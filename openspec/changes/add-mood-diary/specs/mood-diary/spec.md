# Дельта-спецификация: mood-diary

Из этого change'а в `mood-diary` осталось одно требование: отзыв токена виджета. Остальное (отметка, график, итоги недели, журнал внутри «Дневника») уже в базе `openspec/specs/mood-diary`. Сегменты «Дневника», включая «Тесты» в мобильном клиенте, уже в базе.

## MODIFIED Requirements

### Requirement: Токен виджета в API

API SHALL выдавать токен для быстрой отметки на `POST /api/diary/widget-token` (токен вида `wdg_…` показывается один раз, в хранилище остаётся только хеш; новый токен отзывает прежний) и отзывать его на `DELETE /api/diary/widget-token`. По заголовку `Authorization: Widget <token>` SHALL работать только `GET /api/diary/widget/today` и `PUT /api/diary/widget/checkin` (отметка с источником `widget`, не чаще 120 запросов в минуту с одного адреса); остальные маршруты токен виджета не принимают, а токен сессии не принимается маршрутами виджета. Токен принадлежит человеку, а не сеансу, и MUST отзываться, когда человек завершает свои сеансы массово (`POST /api/auth/logout-all` с `keepCurrent` и без), при смене пароля (она завершает остальные сеансы) и при блокировке аккаунта; при выходе из приложения на телефоне с виджетом приложение отзывает токен само перед выходом. Токены удаляются вместе с аккаунтом. Запрос с отозванным токеном получает `401`.

Поверхности: api · android

#### Scenario: (API) Токен не открывает остального
- **WHEN** запрос с токеном виджета обращается к `/api/diary` или `/api/dialogs`
- **THEN** ответ `401`

#### Scenario: (API) Отметка с токеном
- **WHEN** по токену виджета отправлена отметка
- **THEN** она видна в дневнике с источником `widget`

#### Scenario: (API) Новый токен
- **WHEN** выдан второй токен
- **THEN** первый отвечает `401`

#### Scenario: (API) Выход на всех устройствах
- **WHEN** человек завершил все свои сеансы (`logout-all`, с `keepCurrent` или без)
- **THEN** запрос с прежним токеном виджета получает `401`, отметка не сохраняется

#### Scenario: (API) Смена пароля
- **WHEN** человек сменил пароль
- **THEN** запрос с прежним токеном виджета получает `401`

#### Scenario: (API) Блокировка
- **WHEN** аккаунт заблокирован
- **THEN** запрос с прежним токеном виджета получает `401`, а после разблокировки токен не возвращается: нужен новый

#### Scenario: (Android) Выход из приложения
- **WHEN** человек выходит из аккаунта в приложении на телефоне с виджетом
- **THEN** приложение отзывает токен (`DELETE /api/diary/widget-token`) до выхода, и запрос с этим токеном получает `401`

# Дельта-спецификация: native-app-build

Локальные напоминания в Android требуют разрешения `POST_NOTIFICATIONS`; база пока разрешает только три.

## MODIFIED Requirements

### Requirement: Разрешения и платформенные параметры

Android-приложение SHALL запрашивать только разрешения `INTERNET`, `RECORD_AUDIO`, `ACCESS_NETWORK_STATE` и `POST_NOTIFICATIONS` (Android 13 и новее); `POST_NOTIFICATIONS` MUST запрашиваться не при запуске, а только после ответа «Да» на вопрос вида уведомления в приложении (capability `notifications`); наличие микрофона MUST NOT быть обязательным для установки (`required="false"`: разговор можно вести текстом); `CALL_PHONE` MUST NOT запрашиваться, потому что кнопка SOS и номера линий помощи только набирают номер, звонок начинает человек. Минимальная версия Android — API 24, целевая и компилируемая — API 36. iOS-приложение SHALL содержать пояснение для микрофона («Микрофон нужен, чтобы вы могли говорить вслух. Запись не сохраняется: речь распознаётся в момент разговора.»), поддерживать iOS 15.0 и новее, всегда использовать тёмный стиль интерфейса, объявлять `ITSAppUsesNonExemptEncryption` равным `false` и поддерживать на iPhone только портретную ориентацию (на iPad — портретную и перевёрнутую портретную). Android-приложение MUST NOT попадать в резервные копии и переносы на новый телефон: `allowBackup` равен `false`, а правила извлечения данных исключают из облачного бэкапа и из переноса все домены (`root`, `file`, `database`, `sharedpref`, `external`), потому что в хранилище лежат токены сессии и ключ устройства.

Поверхности: android · ios

#### Scenario: Телефон без микрофона
- **WHEN** (android) приложение ставится на устройство без микрофона
- **THEN** установка не блокируется

#### Scenario: SOS
- **WHEN** (android) человек нажимает на номер линии помощи
- **THEN** набирается номер без разрешения `CALL_PHONE`, звонок начинает человек

#### Scenario: Первый запрос микрофона на iOS
- **WHEN** (ios) система впервые запрашивает доступ к микрофону
- **THEN** показывается пояснение из `NSMicrophoneUsageDescription`

#### Scenario: Перенос на новый телефон
- **WHEN** (android) человек переносит данные со старого телефона на новый
- **THEN** данные приложения не переносятся, на новом телефоне нужно войти заново

#### Scenario: Запрос уведомлений
- **WHEN** (android) на Android 13 или новее человек впервые запускает приложение
- **THEN** системного запроса на уведомления нет, он появляется только после «Да» на вопрос о напоминании

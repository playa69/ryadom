# Proposal: add-notifications

## Why

В приложении нет ни одного уведомления: ни push, ни локальных, ни сообщений бота. Первым они нужны дневнику настроения (`add-mood-diary`): у конкурента ежедневное напоминание включено по умолчанию и держит привычку отмечаться. Дальше придут «утром бережный пуш» из сценария А `docs/spec.md` и «итоги недели готовы».

Уведомления — отдельная инфраструктура со своими рисками:
- разрешения не на первом экране;
- одна доставка при нескольких репликах;
- окно и пауза, чтобы не стать навязчивыми;
- ничего личного на экране блокировки;
- нативная часть выходит только с новой сборкой APK.

Поэтому делаем её отдельным change'ем, а напоминание о настроении — его первым видом.

## What Changes

- **Каналы:**
  - локальные уведомления в нативных сборках (`@capacitor/local-notifications`, `POST_NOTIFICATIONS` в Android);
  - Web Push в PWA и вебе (VAPID, обработчики `push` и `notificationclick` в сервис-воркере);
  - сообщения бота в Telegram Mini App (`requestWriteAccess`, Bot API `sendMessage`).
- **Согласие перед системным разрешением.** Сначала вопрос в приложении, потом системный запрос. Никогда — при запуске, в онбординге и в разговоре.
- **Настройки по видам уведомлений** (`notification_preferences`) и подписки устройств (`push_subscriptions`).
- **Минутный планировщик** в шлюзе:
  - одна доставка на вид и местный день (`notification_deliveries` с уникальным ключом);
  - окно 08:00–23:00, пропуск больше 2 часов — без доставки;
  - пауза после 7 неоткрытых.
- **Открытие:** ссылка ведёт на нужный экран, открытие учитывается.
- **Напоминание о настроении** (`mood-reminders`):
  - включено по умолчанию, 20:00;
  - не после отметки и не во время разговора (в нативных сборках без серверного push — с ограничением, `design.md`, D5);
  - бережные тексты без личных данных.
- **Аналитика без содержимого**, удаление вместе с аккаунтом, снятие подписки при выходе.

## Capabilities

### New Capabilities

- `notifications`: каналы, разрешения, подписки, планировщик, окно, пауза, открытие, приватность, выход и удаление.
- `mood-reminders`: напоминание о настроении (перенесено из `add-mood-diary`).

### Modified Capabilities

- (нет)

## Impact

- **`app/packages/db`:** миграция `0011_notifications`. Зависит от `0009_mood_diary`: нужны `users.timezone` и `mood_checkins`. Идёт после `0010_self_check` и генерируется после ребейза на `main` (порядок слияния и миграций — `design.md`, Migration Plan).
- **`app/packages/contracts/src/api/notifications.ts`, `app/packages/core`:** процессы уведомлений, интеграции Web Push и Telegram Bot API.
- **`app/services/api`:** маршруты `/api/notifications/*`, тик планировщика в `src/index.ts`.
- **`app/apps/mobile`:** `src/sw/sw.ts` (push), `lib/notifications.ts`, плагин `@capacitor/local-notifications`, `android/` (разрешение). Нативное — новой сборкой APK.
- **`app/apps/web`:** подписка Web Push, сервис-воркер для push.
- **`app/packages/analytics`:** события `notification_*`.
- **`k8s/app`:** ключи VAPID в Secret `app-secrets`, флаг `NOTIFICATIONS_ENABLED`.
- **Документы:** `REQ-WELL-04` в `docs/spec.md` ссылается на этот change.

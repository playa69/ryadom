## ADDED Requirements

### Requirement: Наблюдаемость фактического голосового пути
Агент SHALL записывать в трассировку хода диалога провайдера и модель фактически обслуживающего его соединения: `sber` с моделью GigaChat или `gemini` с настроенной моделью Gemini Live, а tags MUST включать `voice` и фактического провайдера. Техническое открытие соединения MUST NOT создавать отдельную generation и SHALL оставаться наблюдаемым через журналы и метрики. При fallback и поздней готовности соединения атрибуция активного хода и её prompt components MUST обновляться по фактической ссылке; при полном отказе модель MUST NOT присваиваться несработавшему провайдеру. Prompt links, учёт usage и запрет текстов реплик MUST сохраняться.

Поверхности: agent

#### Scenario: Ход Сбера
- **WHEN** диалог ведёт ход по пути Сбера
- **THEN** generation хода содержит `provider=sber`, модель GigaChat, tags `voice`, `sber` и prompt components Сбера, а отдельная generation открытия не создаётся

#### Scenario: Ход Gemini Live
- **WHEN** диалог ведёт ход по пути Gemini Live
- **THEN** generation хода содержит `provider=gemini`, настроенную модель Gemini Live, tags `voice`, `gemini` и prompt components Gemini, а отдельная generation открытия не создаётся

#### Scenario: Запасной путь принял сессию
- **WHEN** основной путь не открылся, а запасной принял соединение и обслужил ход
- **THEN** ход содержит провайдера, модель и prompt components запасного соединения, а не отказавшего основного пути

#### Scenario: Соединение открылось после начала хода
- **WHEN** трасса хода создана до завершения открытия соединения
- **THEN** после готовности ссылки ход получает её провайдера, модель, tags и prompt components вместо `provider=unknown`

#### Scenario: Сессия не открылась
- **WHEN** ни основной, ни запасной путь не смог открыть соединение
- **THEN** ошибка остаётся видна в журналах и метриках, отдельная generation открытия не создаётся, а модель несработавшего провайдера не присваивается ходу

#### Scenario: Промпты и приватность сохранены
- **WHEN** агент обновляет атрибуцию провайдера активного хода
- **THEN** связанные промпты и их версии соответствуют фактическому пути, usage и маскирование текстов остаются прежними

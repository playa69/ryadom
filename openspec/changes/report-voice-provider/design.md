## Context

Общий `DialogSession` начинает generation до вызова соединителя и сейчас передаёт модель Gemini из конфигурации. Основной и запасной пути реализуют один интерфейс соединения, а fallback возвращает ссылку уже выбранного пути. Конфигурация поэтому не может служить источником фактической атрибуции.

## Goals / Non-Goals

**Goals:**

- Один источник provider/model для трасс открытия и ходов.
- Корректная атрибуция fallback и ошибок без влияния на диалог.
- Сохранение prompt links, usage и приватности.

**Non-Goals:**

- Изменение выбора пути, моделей, промптов, публичного API или ConfigMap.
- Переименование метрик Prometheus и журналов, не относящихся к Langfuse.

## Decisions

1. **`LiveLink` — источник истины.** Ссылка Gemini получает `provider="gemini"` и модель соединителя, ссылка Сбера — `provider="sber"` и существующий `CHAT_MODEL`. Fallback не требует собственной логики атрибуции. Альтернатива — provider из ConfigMap — отклонена: она неверна при fallback.
2. **Открытие начинается без модели.** Нейтральная generation `voice_session_open` сохраняет измерение длительности и ошибок. После успешного `open()` observation получает `link.model`, metadata `provider` и tags `voice`, `<provider>`. При ошибке модель остаётся `None`.
3. **Ход обновляется по ссылке, которая его обслуживает.** Начальная идентичность берётся из текущей ссылки, если она уже есть, и уточняется после открытия/восстановления. Это исключает сохранение первичного провайдера после fallback.
4. **Tracer поддерживает позднюю идентичность.** `Observation.update` принимает `model` и `tags`; tags обновляются через trace. Ошибки SDK по-прежнему маскируются журналом и не влияют на разговор.
5. **Совместимость поведения.** Меняются только наблюдаемые поля Langfuse; имена `live_turn_*`, prompt objects, usage и версии приложения сохраняются.

## Risks / Trade-offs

- [Позднее обновление model/tags не поддержано SDK] → проверить маппинг на поддельном SDK и реальном Langfuse после выката; сбой не должен влиять на диалог.
- [Трасса хода завершится до обновления идентичности] → обновлять при получении ссылки до `trace.end()` и покрыть fallback тестами.
- [Старые фильтры по `gemini_session_open`/`gemini_live` перестанут находить новые трассы] → это намеренное исправление; задокументировать нейтральное имя и новые tags в PR.

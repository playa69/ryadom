## Context

Общий `DialogSession` начинает generation до вызова соединителя и сейчас передаёт модель Gemini из конфигурации. Основной и запасной пути реализуют один интерфейс соединения, а fallback возвращает ссылку уже выбранного пути. Конфигурация поэтому не может служить источником фактической атрибуции.

## Goals / Non-Goals

**Goals:**

- Один источник provider/model для трасс фактических ходов.
- Корректная атрибуция fallback, позднего открытия и ошибок без влияния на диалог.
- Сохранение prompt links, usage и приватности без лишних generation.

**Non-Goals:**

- Изменение выбора пути, моделей, промптов, публичного API или ConfigMap.
- Переименование метрик Prometheus и журналов, не относящихся к Langfuse.

## Decisions

1. **`LiveLink` — источник истины.** Ссылка Gemini получает `provider="gemini"` и модель соединителя, ссылка Сбера — `provider="sber"` и существующий `CHAT_MODEL`. Fallback не требует собственной логики атрибуции. Альтернатива — provider из ConfigMap — отклонена: она неверна при fallback.
2. **Открытие не является модельным вызовом.** Отдельная generation `voice_session_open` удаляется и не заменяется другим объектом Langfuse. Длительность, назначение и ошибки открытия остаются в журналах и существующих метриках Prometheus.
3. **Ход обновляется по ссылке, которая его обслуживает.** Начальная идентичность берётся из текущей ссылки, если она уже есть, и уточняется после открытия/восстановления. Это исключает `unknown` после позднего открытия и сохранение первичного провайдера после fallback.
4. **Prompt metadata и components обновляются вместе с идентичностью.** Позднее обновление активного хода повторяет `prompt_name`, `prompt_version`, `prompt_source` основной инструкции и передаёт актуальный набор компонентов: SDK не должен потерять основной prompt link, а после перехода на Сбер не остаётся только набор Gemini.
5. **Tracer поддерживает позднюю идентичность.** `Observation.update` принимает `model` и `tags`; tags обновляются через trace. Ошибки SDK по-прежнему маскируются журналом и не влияют на разговор.
6. **Совместимость поведения.** Меняется только трассировка Langfuse; имена `live_turn_*`, prompt objects, usage и версии приложения сохраняются.

## Risks / Trade-offs

- [Позднее обновление model/tags не поддержано SDK] → проверить маппинг на поддельном SDK и реальном Langfuse после выката; сбой не должен влиять на диалог.
- [Трасса хода завершится до обновления идентичности] → обновлять при получении ссылки до `trace.end()` и покрыть задержку открытия и fallback тестами.
- [Старые фильтры по `voice_session_open` не находят новые записи] → это намеренное удаление лишней generation; исторические записи сохраняются, новые ходы находятся по `live_turn_*` и provider tags.

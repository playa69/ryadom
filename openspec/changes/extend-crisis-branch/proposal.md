Задача: PROTEUS-279

## Зачем

Концепция «Голосовой собеседник v1» (раздел «Кризисная ветка: скрипт», `REQ-SAFE-01`, `REQ-SAFE-03`, `REQ-SAFE-06`, `REQ-SAFE-07`, `REQ-PRD-06`) требует от кризисной ветки больше, чем есть в `main`. Сейчас: пять фраз-триггеров, одна фиксированная фраза, лист помощи по кадру `safety`, уровня «жёлтый» нет, второй ступени детектора нет (ловит около 1 из 3 случаев), вопроса о безопасности, закреплённой кнопки звонка, возврата после звонка и пуша нет.

## Что меняется

- Детектор в две ступени: словарь (расширенный, красный и жёлтый уровни) и ступень на модели для реплик, которых словарь не поймал. Ступень на модели только расширяет охват; ответ по-прежнему фиксированный (`CON-TECH-07`).
- Скрипт красного уровня по шагам: фраза с именем, лист помощи, вопрос «ты сейчас в безопасности?», ветки «да» и «нет/не знаю», редкое напоминание, фраза после возврата из звонка.
- Жёлтый уровень: прямой вопрос о мыслях не жить; «да» ведёт в красный уровень, «нет» — в спокойный разговор с плашкой «Нужна помощь?».
- Спокойный режим на время кризиса: без шуток, упражнений (кроме заземления), итога и вопроса «стало легче?»; шарик без улыбки и без пульсации.
- Закреплённая кнопка «Позвонить сейчас» до конца сессии.
- Один пуш через несколько часов после ухода из кризисного разговора, без темы, открывает лист помощи (при согласии на пуши).
- Событие `safety_signal` получает источник срабатывания (словарь или модель).
- Тексты скрипта лежат в одном месте (конфиг), чтобы психолог и юрист правили их без изменения логики (`CON-ETH-04`).

## Влияние

capability `crisis-safety` (дельта), точечно `push-notifications`, `orb-mood`, `product-analytics`, `dialog-recaps` (по ссылке из `crisis-safety`). Затронуты agent, api, web, pwa, android, ios, tg. Контракт кадра `safety` расширяется необязательными полями (`stage`, `showCall`); старые клиенты продолжают открывать лист (проверка по `release-check`).

## Не входит

Каталог групп и специалистов («Люди рядом»), «Кому из твоих позвонить» (`REQ-SAFE-05`), номера для регионов вне Москвы.

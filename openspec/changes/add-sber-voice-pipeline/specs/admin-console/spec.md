## MODIFIED Requirements

### Requirement: Каркас админки
Разделы админки SHALL открываться в общем каркасе: боковое меню фиксированной ширины с пунктами «Пользователи» (`/users`), «Голос» (`/voice`) и «Журнал действий» (`/audit`), шапка с адресом вошедшего администратора, подписью «Администратор» и кнопкой «Выйти», внизу меню — ссылка «Перейти на сайт» на публичный сайт в новой вкладке (см. `landing-site`). Админка MUST быть рассчитана на экран рабочего места; раскладки для телефона (сворачиваемое меню, карточки вместо таблиц) в ней нет, и это не дефект. Аналитики продукта в админке нет. Проба `GET /admin/api/health` SHALL проверять базу данных: 200 и `{"status":"ok"}` при исправной базе, иначе 503 и `{"status":"error"}`.

Поверхности: admin

#### Scenario: Навигация
- **WHEN** администратор находится на карточке пользователя
- **THEN** в меню подсвечен пункт «Пользователи», а переход в «Журнал действий» открывает `/audit`, в «Голос» — `/voice`

#### Scenario: Переход на сайт
- **WHEN** администратор нажимает «Перейти на сайт»
- **THEN** сайт открывается в новой вкладке

#### Scenario: Проба при недоступной базе
- **WHEN** база данных недоступна
- **THEN** `/admin/api/health` отвечает 503 и `{"status":"error"}`

### Requirement: Журнал действий
Страница `/audit` SHALL показывать журнал действий администраторов над аккаунтами и голосовым путём, от новых к старым, по 50 записей на странице: время по Москве и адрес администратора, действие («Заблокирован», «Разблокирован», «Почта подтверждена вручную», «Аккаунт удалён», «Сессии завершены», «Голосовой путь изменён»), почта аккаунта на момент действия со ссылкой на его карточку (у записи без аккаунта — «—»), подробности (пустые — «—»; у смены пути — «было: Gemini Live, стало: Сбер»). Параметр `user` сужает журнал до одного аккаунта (ссылка «Показать все» возвращает полный). Записи MUST NOT редактироваться и удаляться через интерфейс; журнал пишется внутри той же операции, что и действие. Пустой журнал показывает «Пока ничего не происходило.».

Поверхности: admin

#### Scenario: Журнал после действий
- **WHEN** администратор заблокировал аккаунт
- **THEN** вверху журнала запись с его адресом, действием «Заблокирован» и почтой аккаунта

#### Scenario: Смена голосового пути в журнале
- **WHEN** администратор переключил путь с «Сбер» на «Gemini Live»
- **THEN** вверху журнала запись с его адресом, действием «Голосовой путь изменён», «—» вместо аккаунта и подробностями «было: Сбер, стало: Gemini Live»; в журнале одного аккаунта её нет

#### Scenario: Один аккаунт
- **WHEN** администратор переходит по ссылке «Что администраторы делали с этим аккаунтом»
- **THEN** журнал показывает только записи об этом аккаунте и ссылку «Показать все»

#### Scenario: Журнал без записей
- **WHEN** действий администраторов ещё не было
- **THEN** показано «Пока ничего не происходило.»

## ADDED Requirements

### Requirement: Выбор голосового пути
Страница `/voice` («Голос») SHALL показывать, каким путём агент ведёт голос новых разговоров, и давать его выбрать: «Сбер» (GigaASR → GigaChat → SaluteSpeech, один женский голос, запасной путь — Gemini Live) или «Gemini Live» (речь в речь, голос из профиля человека). Действующий путь отмечен «Сейчас», под выбором — кто и когда его менял по московскому времени, а пока выбора не было — «Не меняли: действует путь по умолчанию — Сбер». Кнопка «Сохранить» MUST быть неактивна, пока выбран действующий путь. Сохранение MUST заново проверять сессию администратора, записывать путь в базу приложения и запись «Голосовой путь изменён» в журнал действий одной операцией и показывать «Голосовой путь сохранён: «<путь>». Действует со следующего старта разговора.». Сохранение того же пути, что уже действует (например, другой администратор успел раньше), ничего не меняет и в журнал не пишется. Выбор действует на все аккаунты со следующего старта разговора, в том числе возобновлённого (см. `dialog-voice`, «Голосовой путь разговора»); открытые разговоры идут прежним путём.

Поверхности: admin · api · agent

#### Scenario: Первое открытие
- **WHEN** администратор впервые открывает «Голос»
- **THEN** отмечен «Сбер» с пометкой «Сейчас», написано «Не меняли: действует путь по умолчанию — Сбер», «Сохранить» неактивна

#### Scenario: Переключение пути
- **WHEN** администратор выбирает «Gemini Live» и нажимает «Сохранить»
- **THEN** показано «Голосовой путь сохранён: «Gemini Live». Действует со следующего старта разговора.», пометка «Сейчас» у «Gemini Live», под выбором — его адрес и время, в журнале действий — запись «Голосовой путь изменён»
- **AND** следующий старт любого разговора передаёт агенту `pipeline: "gemini"`

#### Scenario: Тот же путь
- **WHEN** два администратора одновременно сохраняют «Gemini Live»
- **THEN** путь — «Gemini Live», а в журнале одна запись о смене

#### Scenario: Сессия истекла
- **WHEN** сессия администратора истекла, а он нажимает «Сохранить»
- **THEN** путь не меняется, администратор попадает на экран входа

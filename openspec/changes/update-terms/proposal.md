## Why

Владелец предоставил новую редакцию пользовательского соглашения от 05.11.2026. Текущая страница `/terms` содержит сокращённый документ из 12 разделов и устаревшие положения об обязательной регистрации по почте, поэтому её нужно заменить предоставленным текстом без самостоятельных редакторских поправок.

## What Changes

- `/terms` получает полный заголовок «Пользовательское соглашение сервиса «Рядом»», дату и адрес публикации, выделенный блок «Главное» и 14 разделов предоставленной редакции.
- Добавляются условия о принятии публичной оферты, отдельном согласии на обработку персональных данных, модели GigaChat и SaluteSpeech, границах ИИ, безопасности, аккаунте без обязательной регистрации, уведомлениях и правилах использования.
- Добавляются разделы о бесплатности, интеллектуальной собственности, ответственности, изменении и прекращении сервиса, условиях App Store и других площадок, применимом праве и спорах.
- Контакт владельца и правообладателя — `playasn@yandex.ru`; ссылки на Политику обработки персональных данных и удаление аккаунта ведут на `/privacy` и `/delete-account`.
- Текст публикуется как статическое содержимое публичной страницы. Фактическое поведение аккаунта, переноса, уведомлений, кризисного протокола и магазинов этим change не меняется.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `landing-site`: новая редакция пользовательского соглашения и проверки его публичного отображения.

## Impact

| Поверхность | Затрагивается |
| ----------- | ------------- |
| agent       | нет           |
| api         | нет           |
| web         | нет           |
| pwa         | нет           |
| android     | нет           |
| ios         | нет           |
| tg          | нет           |
| admin       | нет           |
| landing     | да            |

Меняются статическая страница лендинга, её e2e, макет и скриншоты. Контракт API, база, зависимости, нативный код и конфигурация кластера не меняются. Для выката нужен только образ landing; миграций нет.

`update-privacy-policy` изменяет то же требование `landing-site` «Политика конфиденциальности и пользовательское соглашение» и поддержку в подвале `/terms`. Change не зависит от него по коду, но при архивации вторым его дельту нужно перенести на обновлённую спеку, сохранив обе редакции документов. При объединении веток также сохранить новую почту окружения из `update-privacy-policy` и фиксированный контакт Оператора из этого текста.

Подтверждённые расхождения предоставленной редакции с текущим продуктом фиксируются в `design.md` и PR; владельцу текст не переписывается.

Вне рамок: правки `/privacy` и `/consent`, реализация QR-переноса или новых уведомлений, изменение голосового провайдера и механизмов ограничения доступа, юридическая оценка, мёрж и выкат.

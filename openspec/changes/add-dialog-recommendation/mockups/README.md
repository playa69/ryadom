# Карточка на текущих экранах «Рядом»

Экраны сняты на локальном стенде с мок-агентом из `origin/main` на коммите `60d29ec7`. Использованы штатные светлая и тёмная темы. В вариантах с карточкой эскиз и синтетический ответ добавлены в DOM на время съёмки.

| Web, чат, 1280 × 900 | Тёмная | [Экран](reference-web-chat-1280-dark.png) | [Под ответом](web-chat-1280-dark.png) |
| PWA, голос, 390 × 844 | Светлая | [Экран](reference-pwa-voice-390-light.png) | [Под шаром](pwa-voice-390-light.png) |

## Где меняется тема

Переключатель находится справа сверху на главной. На экране разговора применяется выбранная на главной тема.

| Главная | Светлая тема | Тёмная тема |
|---|---|---|
| Web, 1280 × 900 | [Солнце перед SOS](reference-web-home-1280-light.png) | [Полумесяц перед SOS](reference-web-home-1280-dark.png) |
| PWA, 390 × 844 | [Солнце вверху справа](reference-pwa-home-390-light.png) | [Полумесяц вверху справа](reference-pwa-home-390-dark.png) |

Тёмные референсы главной сняты после нажатия штатного переключателя. В обеих версиях цветовая схема сохранилась при открытии разговора.

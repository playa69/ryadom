# Дельта-спецификация: admin-console

## ADDED Requirements

### Requirement: Уведомление человеку из карточки

Карточка пользователя SHALL показывать блок «Уведомления»: устройства с подпиской на уведомления в открытых сессиях
(канал «RuStore», пакет приложения — по нему видно release- или dev-сборку, последнее обновление подписки по Москве) или «Нет
устройств с включёнными уведомлениями.», и форму с полями «Заголовок» (до 60 символов) и «Текст» (до 500), подсказкой
«Текст видно на экране блокировки: без личного» и кнопкой «Отправить». Отправка MUST заново проверять сессию
администратора, отправлять уведомление на все устройства человека (`push-notifications`, «Доставка через RuStore
Push») и показывать итог «Отправлено на N из M устройств»; если ни одно устройство не приняло — «Не отправлено ни на
одно устройство» с причиной («нет устройств с включёнными уведомлениями» или «push-сервис не принял»). Каждая отправка
пишет в журнал действий запись «Уведомление отправлено» с заголовком, текстом и итогом. Пустой заголовок или текст и
превышение длины MUST давать ошибку у поля без отправки. У удалённого аккаунта блока нет.

Поверхности: admin · api

#### Scenario: Отправка на телефон
- **WHEN** у человека одно устройство с включёнными уведомлениями, и администратор отправляет «Обновление» / «Завтра с 10:00 до 10:15 разговоры недоступны»
- **THEN** push-сервис получает сообщение с этим заголовком и текстом на токен устройства, показано «Отправлено на 1 из 1 устройства», в журнале действий — запись «Уведомление отправлено»

#### Scenario: Нет устройств
- **WHEN** у человека нет устройств с включёнными уведомлениями
- **THEN** в блоке написано «Нет устройств с включёнными уведомлениями.», а отправка показывает «Не отправлено ни на одно устройство: нет устройств с включёнными уведомлениями»

#### Scenario: Токен устарел
- **WHEN** push-сервис отвечает, что токен устройства не найден
- **THEN** показано «Не отправлено ни на одно устройство: push-сервис не принял», устройство пропало из блока

#### Scenario: Пустой текст
- **WHEN** администратор нажимает «Отправить» с пустым текстом
- **THEN** у поля «Текст» ошибка, ничего не отправлено и в журнал не записано

## MODIFIED Requirements

### Requirement: Журнал действий
Страница `/audit` SHALL показывать журнал действий администраторов над аккаунтами и голосовым путём, от новых к старым, по 50 записей на странице: время по Москве и адрес администратора, действие («Заблокирован», «Разблокирован», «Почта подтверждена вручную», «Аккаунт удалён», «Сессии завершены», «Уведомление отправлено», «Голосовой путь изменён»), почта аккаунта на момент действия со ссылкой на его карточку (у записи без аккаунта — «—»), подробности (пустые — «—»; у смены пути — «было: Gemini Live, стало: Сбер»; у уведомления — «заголовок: …, текст: …, отправлено: 1 из 1»). Параметр `user` сужает журнал до одного аккаунта (ссылка «Показать все» возвращает полный). Записи MUST NOT редактироваться и удаляться через интерфейс; журнал пишется внутри той же операции, что и действие. Пустой журнал показывает «Пока ничего не происходило.».

Поверхности: admin

#### Scenario: Журнал после действий
- **WHEN** администратор заблокировал аккаунт
- **THEN** вверху журнала запись с его адресом, действием «Заблокирован» и почтой аккаунта

#### Scenario: Смена голосового пути в журнале
- **WHEN** администратор переключил путь с «Сбер» на «Gemini Live»
- **THEN** вверху журнала запись с его адресом, действием «Голосовой путь изменён», «—» вместо аккаунта и подробностями «было: Сбер, стало: Gemini Live»; в журнале одного аккаунта её нет

#### Scenario: Уведомление в журнале
- **WHEN** администратор отправил человеку уведомление
- **THEN** вверху журнала запись с его адресом, действием «Уведомление отправлено», почтой аккаунта и подробностями с заголовком, текстом и итогом

#### Scenario: Один аккаунт
- **WHEN** администратор переходит по ссылке «Что администраторы делали с этим аккаунтом»
- **THEN** журнал показывает только записи об этом аккаунте и ссылку «Показать все»

#### Scenario: Журнал без записей
- **WHEN** действий администраторов ещё не было
- **THEN** показано «Пока ничего не происходило.»

# Дельта-спецификация: native-app-build

## MODIFIED Requirements

### Requirement: Нативные возможности клиента
Нативная сборка SHALL использовать плагины Capacitor: защищённое хранилище платформы (Android Keystore, iOS Keychain) для токена продления сессии и ключа устройства для входа без регистрации; хранилище настроек для записи о человеке (чтобы экран не был пустым без сети); приложение (номер сборки, состояние, аппаратная кнопка «назад»); браузер (внешние ссылки открываются в Custom Tabs); панели статуса и заставку; клавиатуру; обновления пакетов интерфейса; в Android — уведомления RuStore Push (разрешение, токен, удаление токена, касание уведомления). Android-приложение SHALL подключаться к пуш-проекту своего варианта: `dev` — к проекту «Тест» (пакет `ru.ryadom.companion.dev`, командный debug-ключ), `prod` — к проекту «Production» (пакет `ru.ryadom.companion`, релизный ключ); сервисный токен пуш-проекта MUST NOT попадать в сборку. Токен продления и ключ устройства MUST NOT храниться в открытых настройках. Приложение сообщает API номер сборки (Android `versionCode`, iOS номер сборки) целым числом; если прочитать его не удалось, проверки версий не выполняются (см. `app-updates`).

Поверхности: android · ios

#### Scenario: Токены
- **WHEN** человек входит в аккаунт в нативной сборке
- **THEN** токен продления лежит в защищённом хранилище платформы, а в настройках — только запись о человеке

#### Scenario: Внешняя ссылка
- **WHEN** человек открывает «Условия использования» из профиля
- **THEN** документ открывается в Custom Tabs, а не внутри WebView приложения

#### Scenario: (Android) Пуш-проект варианта
- **WHEN** собирается вариант `dev`
- **THEN** приложение подписывается на уведомления в пуш-проекте «Тест» и сообщает серверу его идентификатор; вариант `prod` — в проекте «Production»

### Requirement: Разрешения и платформенные параметры
Android-приложение SHALL запрашивать только разрешения `INTERNET`, `RECORD_AUDIO`, `ACCESS_NETWORK_STATE` и `POST_NOTIFICATIONS`; наличие микрофона MUST NOT быть обязательным для установки (`required="false"`: разговор можно вести текстом); `CALL_PHONE` MUST NOT запрашиваться, потому что кнопка SOS и номера линий помощи только набирают номер, звонок начинает человек. `POST_NOTIFICATIONS` запрашивается во время работы только после того, как человек включил уведомления в профиле (`push-notifications`, «Включение уведомлений на телефоне»). Минимальная версия Android — API 24, целевая и компилируемая — API 36. iOS-приложение SHALL содержать пояснение для микрофона («Микрофон нужен, чтобы вы могли говорить вслух. Запись не сохраняется: речь распознаётся в момент разговора.»), поддерживать iOS 15.0 и новее, всегда использовать тёмный стиль интерфейса, объявлять `ITSAppUsesNonExemptEncryption` равным `false` и поддерживать на iPhone только портретную ориентацию (на iPad — портретную и перевёрнутую портретную). Android-приложение MUST NOT попадать в резервные копии и переносы на новый телефон: `allowBackup` равен `false`, а правила извлечения данных исключают из облачного бэкапа и из переноса все домены (`root`, `file`, `database`, `sharedpref`, `external`), потому что в хранилище лежат токены сессии и ключ устройства.

Поверхности: android · ios

#### Scenario: Телефон без микрофона
- **WHEN** (Android) приложение ставится на устройство без микрофона
- **THEN** установка не блокируется

#### Scenario: SOS
- **WHEN** (Android) человек нажимает на номер линии помощи
- **THEN** набирается номер без разрешения `CALL_PHONE`, звонок начинает человек

#### Scenario: Первый запрос микрофона на iOS
- **WHEN** (iOS) система впервые запрашивает доступ к микрофону
- **THEN** показывается пояснение из `NSMicrophoneUsageDescription`

#### Scenario: Перенос на новый телефон
- **WHEN** (Android) человек переносит данные со старого телефона на новый
- **THEN** данные приложения не переносятся, на новом телефоне нужно войти заново

#### Scenario: (Android) Разрешение на уведомления
- **WHEN** приложение на Android 13 и новее запущено впервые
- **THEN** запроса `POST_NOTIFICATIONS` нет, пока человек не включил «Уведомления» в профиле

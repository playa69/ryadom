## Решения

- Причина — код из закрытого списка (`agent/app/core/reasons.py`), выводится из исключения или текста ошибки. Закрытый список годится и для label Prometheus, и для свойства PostHog: текст вендора наружу не уходит. Шлюз принимает только значения из списка, остальное превращает в `unknown`.
- Вендор (`gigaasr`, `gigachat`, `salutespeech`, `gemini_live`, `gemini_tts`) — label метрики ошибок; роль (`stt`, `live`, `tts`…) остаётся в `agent_component_calls_total` и `component_called`.
- Отказы считает один слой: соединители при открытии, соединение Сбера через событие `closed` (сессия считает, только если ход шёл), озвучка — `FallbackTts`. Закрытие между репликами (GoAway) в ошибки не идёт.
- `pipeline` в событии — фактический путь соединения (`LiveLink.provider`), а не запрошенный: после перехода на запасной путь он другой.

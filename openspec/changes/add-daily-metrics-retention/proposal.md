Задача: PROTEUS-343

## Why

Система сбора Sber500 запрашивает ежедневные метрики и численность вернувшихся для каждой когорты регистрации. В репозитории есть API дашборда, а маршрута для автоматической выгрузки пока нет.

## What Changes

- Добавить защищённый GET /api/v1/metrics/daily с диапазоном до 90 московских суток.
- Определять когорту по дате создания аккаунта. Считать D1, D3, D7 и D14 по тому же событию, что и DAU.
- Восстановить доступную историю активности в фоне и хранить агрегаты закрытых суток.
- Показать регистрации и удержание по когортам на странице дашборда.

## Capabilities

### Modified Capabilities

- `sber500-dashboard` получает отдельный контракт ежедневной выгрузки для коллектора.

## Impact

Сервис dashboard, его PostgreSQL, точный HTTPS-маршрут и отдельный секрет для Bearer-аутентификации.

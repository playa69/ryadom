# Главный экран всех клиентов: удаление второго выбора

## До

```text
[ Поговорить ]

Без памяти                         [ переключатель ]
Следующий разговор не попадёт в память

☐ Не сохранять этот разговор
  Он не попадёт в журнал, итоги и память
```

## После: web, PWA, Android, iOS и Telegram

Переключатель выключен:

```text
[ Поговорить ]

Без памяти                         [ переключатель ]
Я буду запоминать разговор, чтобы лучше узнать тебя
```

Переключатель включен:

```text
[ Поговорить ]

Без памяти                         [ переключатель ]
Я не запомню этот разговор
```

Если память выключена или недоступна, блок «Без памяти» тоже отсутствует. Отдельный пустой блок, вторая галочка и её подсказка не показываются. Остальные элементы экрана сохраняют размеры, порядок и поведение.

Первый экран всех клиентов с кнопкой начала разговора использует то же правило: выбора несохранения нет, разговор сразу сохраняемый. В Telegram отдельный экран согласия не меняется; галочка несохранения отсутствует на активном экране после него.

Задача: PROTEUS-317

## Зачем

После случайного отказа в доступе к микрофону человеку нужна инструкция для его браузера и способ повторить попытку в текущем разговоре. Сейчас сообщение отсылает к настройкам без конкретных шагов.

## Что меняется

- Web и PWA показывают инструкцию по разрешениям браузера, повторную попытку и переход к тексту.
- Клиенты различают отказ и отсутствие устройства. Web и PWA измеряют первый отказ и последующее открытие микрофона в текущем разговоре.

## Влияние

REQ-VOICE-01, capability `dialog-voice`. UI Web и PWA, общий захват звука и клиентская аналитика. Контракты API и нативные разрешения не меняются.

## Why

Сейчас первое сообщение, нажатие «Поговорить» или создание аккаунта одновременно означает согласие на обработку персональных данных. Нужно получить отдельное явное действие человека и показать ему утверждённый текст согласия редакции 1.0 от 05.11.2026.

## What Changes

- Новый пользователь до показа чата проходит отдельный экран с обязательной, по умолчанию снятой отметкой о возрасте 18+, принятии условий и согласии на обработку персональных данных. После отметки и «Продолжить» открывается обычный активный главный экран без повторной отметки; до прохождения ворота поля чата и запуска разговора нет.
- Форма регистрации получает ту же обязательную отметку: без неё регистрация не отправляется. Согласие по-прежнему записывается после подтверждения почты и начала сессии.
- Экран, на котором записывается новое согласие с текущими условиями, использует явную отметку вместо согласия одной кнопкой «Продолжить».
- На публичном сайте появляется `/consent` с предоставленным владельцем полным текстом согласия. Ссылки «согласие на обработку данных» ведут на него; `/privacy` остаётся отдельной политикой обработки персональных данных.
- Версия условий `2026-10-04` не меняется. Аккаунты с уже записанным согласием не получают новый ворот и не обязаны подтверждать его повторно.
- Текст согласия переносится без редакторской переработки; оформляются только структура документа, нумерация шести пунктов и активные ссылки.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `account-auth`: отдельный экран явного согласия перед первым показом чата, отметка при регистрации и при новой записи согласия; существующие согласия не запрашиваются повторно.
- `landing-site`: публичная страница полного текста согласия `/consent` и её связь с политикой.
- `app-shell`: главный экран открывается новому человеку только после входного ворота и показывает активные действия без повторной отметки; у вошедшего человека нового ворота нет.

## Impact

| Поверхность | Затрагивается |
| ----------- | ------------- |
| agent       | нет           |
| api         | нет           |
| web         | да            |
| pwa         | да            |
| android     | да            |
| ios         | да            |
| tg          | да            |
| admin       | нет           |
| landing     | да            |

Изменяются клиентские экраны и ссылки, публичный сайт, unit- и e2e-тесты. Контракт API, схема записи согласий, версия условий, база данных и нативный код не меняются; новых миграций и зависимостей нет. Пересечений с открытыми change'ами по изменяемым требованиям нет.

Вне рамок: повторное согласие действующих пользователей, изменение `/privacy` и `/terms`, редакторская или юридическая проверка предоставленного текста, новые виды обработки данных и выкат в прод.

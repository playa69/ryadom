# Регистрация: явное согласие

## 390 и 1280 px

```text
Давай знакомиться
Аккаунт нужен, чтобы разговоры оставались твоими.

[ Как тебя называть            ]
[ Почта                        ]
[ Пароль                       ]

[ ] Мне есть 18 лет, я принимаю условия
    использования и даю согласие на обработку
    персональных данных, включая голос и текст
    разговоров.

[       Создать аккаунт        ]  ← неактивна до отметки

«Рядом» — ИИ для самоподдержки,
а не психотерапия и не медицинская помощь.
```

После отметки кнопка становится активной. Отправка формы клавишей Enter до отметки также ничего не делает. Ошибки полей и передача пароля только в память остаются прежними.

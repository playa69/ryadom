# Первый вход: отдельное согласие, затем чат

## 390 и 1280 px — входной ворот

```text
[SOS]                         [Войти]

             (шар)
           Добрый вечер
Один раз подтверди, что согласен(на),
— и можно говорить.

[ ] Мне есть 18 лет, я принимаю
    условия использования и даю
    согласие на обработку персональных
    данных, включая голос и текст разговоров.

[          Продолжить           ]  ← неактивна до отметки

«Рядом» — ИИ для самоподдержки,
а не психотерапия и не медицинская помощь.
В опасной ситуации звони 112.
```

До прохождения ворота поля чата, микрофона и «Поговорить» нет. Отметка не создаёт аккаунт и ничего не отправляет.

## После отметки и «Продолжить»

Открывается обычная главная с шаром, полем ввода в вебе либо большой кнопкой «Поговорить» в мобильном клиенте. Действия активны, обязательной отметки уже нет. «Запоминать важное» и «Не сохранять этот разговор» остаются необязательными. Первый запуск создаёт аккаунт и записывает согласие через прежний API.

У вошедшего пользователя с уже записанной текущей версией согласия ни входного ворота, ни обязательной отметки нет: сразу открывается главная.

## MODIFIED Requirements

### Requirement: Сквозная трассировка
Шлюз SHALL передавать агенту на каждый вызов (REST и WebSocket) пять заголовков трассировки: `x-trace-id`, `x-request-time`, `x-client-id`, `x-session-id`, `x-user-id` с текущими значениями запроса клиента; отсутствующее значение уходит пустым заголовком, и принимающий считает его отсутствующим (см. `app-shell`). Агент сегодня заголовки не читает и в своих журналах номера запроса не пишет; `userId` и `dialogId` для связи берутся из пути. Трассы моделей в Langfuse включаются только при заданных ключах проекта, не влияют на разговор (сбой записи — предупреждение в журнал) и группируются по идентификатору диалога. По умолчанию агент SHALL заменять тексты реплик во входах и выходах всех наблюдений числом знаков и слов. При `LANGFUSE_CAPTURE_CONTENT=true` агент SHALL записывать исходные `input` и `output` во все новые корневые и дочерние наблюдения для всех пользователей; при возврате `false` новые наблюдения SHALL снова маскироваться. Динамические тексты в `metadata`, `status_message`, сведениях о prompt components, обычных логах и метриках MUST NOT появляться в любом режиме.

Поверхности: api · agent

#### Scenario: Заголовки на вызове агента
- **WHEN** клиент прислал шлюзу запрос с `x-trace-id: abc-123`, и шлюз вызывает агента
- **THEN** вызов агента несёт `x-trace-id: abc-123` и остальные четыре заголовка

#### Scenario: Заголовка у клиента нет
- **WHEN** клиент не прислал `x-trace-id`
- **THEN** шлюз не придумывает значение, заголовок к агенту уходит пустым

#### Scenario: Трейс без текста
- **WHEN** агент записывает ход диалога в Langfuse, а настройка `LANGFUSE_CAPTURE_CONTENT` не задана или равна `false`
- **THEN** вместо текста реплик во входах и выходах корневого и дочерних наблюдений стоит «[скрыто: N симв., M сл.]»

#### Scenario: Диагностический трейс с текстом
- **WHEN** агент записывает ход любого пользователя в Langfuse с `LANGFUSE_CAPTURE_CONTENT=true`
- **THEN** корневое и дочерние наблюдения содержат исходные `input` и `output` без замены маской

#### Scenario: Остальные поля остаются защищёнными
- **WHEN** агент записывает трассы с `LANGFUSE_CAPTURE_CONTENT=true`
- **THEN** `metadata`, `status_message`, сведения о prompt components, обычные логи и метрики не содержат динамических текстов реплик

#### Scenario: Маскирование снова включено
- **WHEN** после диагностического режима агент перезапущен с `LANGFUSE_CAPTURE_CONTENT=false` и записывает новый ход
- **THEN** входы и выходы новых наблюдений снова содержат маски вместо текста

#### Scenario: Langfuse недоступен
- **WHEN** запись или завершение наблюдения Langfuse завершается ошибкой
- **THEN** разговор продолжается, а предупреждение в журнале не содержит текстов реплик

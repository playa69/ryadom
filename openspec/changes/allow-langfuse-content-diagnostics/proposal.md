## Why

Сейчас Langfuse получает только маски реплик, поэтому по трассе нельзя разобрать содержимое конкретного ответа модели. Нужен управляемый конфигурацией диагностический режим, который позволяет видеть исходные входы и выходы без изменения остальных правил приватности.

## What Changes

- Добавить настройку агента `LANGFUSE_CAPTURE_CONTENT` со значением по умолчанию `false`.
- При `true` записывать во все новые корневые и дочерние наблюдения Langfuse исходные `input` и `output` для всех пользователей.
- При отсутствии настройки или `false` сохранить существующее маскирование текстов.
- Сохранить маскирование `metadata`, `status_message`, сведений о prompt components, обычных логов и метрик в обоих режимах.
- Переключать режим через ConfigMap и rollout агента, без админки и горячего переключателя.
- Привести `CON-DATA-02` и эксплуатационную документацию к новому поведению.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `agent-api`: требование «Сквозная трассировка» разрешает исходные `input` и `output` в Langfuse при включённой диагностической настройке и сохраняет маскирование по умолчанию.

- Код: `agent/app/core/config.py`, `agent/app/core/tracing.py`, тесты агента.

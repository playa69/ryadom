# @ryadom/design

Единственный источник палитры, отступов, типографики и радиусов «Рядом». До появления этого
пакета цвета были скопированы руками в четыре файла и разъехались — например `#1b232d` в вебе
против `#1b2330` в приложении, и два разных красных. Правь значения только здесь.

## Что внутри

- `tokens.css` — `:root { --ryadom-* }`. Импортируют `apps/mobile`, `apps/landing`, `apps/web`, `apps/admin`.
- `stars.css` — звёздное небо одним сидированным SVG-тайлом (переменная `--ryadom-stars`). Подтягивается из `tokens.css` через `@import`; генерируется `node packages/design/gen-stars.mjs`, руками не правится. Слой звёзд + свечение = `--ryadom-atmosphere`; админка берёт только `--ryadom-ambient` и остаётся спокойной.
- `tokens.ts` — те же значения объектом. Импортируют контексты без CSS custom properties —
  сегодня это письма (`@react-email/components` рендерит в статический HTML для почтовых
  клиентов, которые CSS-переменные не поддерживают все и не отовсюду).

`tokens.ts` — не полное зеркало: то, что нужно только CSS (атмосферный градиент, звёзды, кольцо фокуса, стекло),
там не дублируется. Для всего остального значения в обоих файлах должны совпадать. Меняешь общее
значение — меняй сразу оба.

## Как подключают

- **`apps/mobile`** — `import '@ryadom/design/tokens.css'` в `main.tsx`, перед своим
  `styles/tokens.css`. Свой файл оставляет только ремапы `--f7-*`.
- **`apps/landing`**, **`apps/web`**, **`apps/admin`** — тот же импорт в `layout.tsx`. Их `globals.css` объявляет
  свои короткие имена (`--bg`, `--accent`…) как алиасы на `--ryadom-*` — так не пришлось
  переписывать сотни строк, которые их используют.
- **письма** (`packages/core/.../email-renderer-service/shared/theme.ts`) — письма светлые
  (читают их днём в почтовом клиенте), поэтому свои цвета не наследуют напрямую: светлый синий текст тёмного
  интерфейса (`#4da3ff`) на белом даёт контраст ~2,5:1, ниже любого порога WCAG. Тема писем держит собственные, отдельно
  подобранные оттенки того же бренда — и не должна тянуть отсюда цвет для тёмного фона.

## Про apps/web

Правило: `apps/web` не зависит от `packages/*` — так лендинг остаётся
образом без БД и секретов. `@ryadom/design` это не нарушает по сути: в него не попадает ни
строки JS, CSS инлайнится в сборку Next.js, и рантайм-образ лендинга по-прежнему не содержит
кода из `packages/*`. Формально `package.json` перестаёт быть пустым.

## WCAG-исправления

`--ryadom-line-strong`, `--ryadom-text-faint`, `--ryadom-danger-600` несут исправления контраста
из прошлого дизайн-ревью (см. комментарии в `tokens.css`). Не заменяй эти значения «на глаз» —
контраст проверен и запротоколирован.
